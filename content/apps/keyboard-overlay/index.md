Keyboard Overlay draws a see-through keyboard above other windows, including full-screen apps, so you can see which key produces which character in any keyboard layout installed on your Mac. It shows the characters reached with modifier keys, has a shortcut to show or hide the overlay, and lets mouse clicks pass through to the windows underneath. It suits people learning a language or typing on a layout they do not know by heart.

It needs macOS 14 or later and the Accessibility permission, which it uses to detect keyboard events. The README does not say whether release builds are notarized.
