KinetAios is a dashboard for AI coding agents that runs Claude Code, Codex and a built-in ReAct engine in one window. Each session has an engine badge, and the window has file, Git and rules tabs, so several projects can run in parallel. It adds long-term memory, MCP support and skills that load automatically. It is for developers who switch between coding agents and want the sessions in one place. The README says it has no account and no relay: your own API key is the only credential.

The README describes the GitHub DMG builds as unsigned, so macOS Gatekeeper will warn on first launch and you need to allow the app yourself. Apple silicon and Intel DMGs are both published. A Mac App Store version costs $12.99, while the GitHub build is free. The README does not state a minimum macOS version.
