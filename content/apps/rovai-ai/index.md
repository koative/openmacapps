Rovai AI is a workspace where you keep a set of named teammates, each backed by a coding agent that is already installed on your machine, such as Codex CLI, Claude Code, OpenCode or Pi Coding Agent. Teammates share conversations, hand work to each other, and keep agreements and memory across projects, while a mission board tracks longer goals. Each agent does the actual work with its own tools and sign-in. It suits people who run several coding agents on the same codebase and want to see what each one did.

The README lists builds for macOS on Apple silicon and Intel, plus Windows x64, but it does not state a minimum macOS version. Agents must be installed and signed in on the host before teammates can use them. Browser access needs Web access turned on in the desktop app or a separate Rovai Server on your own host, and Feishu and DingTalk channels are provided by the desktop app.
