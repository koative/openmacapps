Avogadro 2 is a molecule editor used in chemistry teaching and research. You draw and edit structures, view them in 3D with several rendering styles, and inspect and analyse the result, working with many common chemical file formats. Its plugin system, including Python plugins, extends it with extra tools and connections to computational chemistry software.

It is developed by the Open Chemistry community, which Kitware started. The code is split between an application repository and a libraries repository, and official releases, including DMGs for Apple silicon and Intel, are published on the libraries repository's release page. Nightly builds are offered for testing new features. Avogadro 2 replaces the original Avogadro 1.x, which is no longer supported.
