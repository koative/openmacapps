Mocolamma is a macOS app for managing Ollama servers. You add one or more servers, including the Ollama instance on the same Mac, and switch between them. For each server it lists the installed models with details, adds or deletes models, and lets you chat with a model to test it. Where the server supports image models, it can also generate images. The author describes it as an unofficial tool that is not affiliated with Ollama. The app itself does not collect data.

It needs macOS 15 or later on Intel or Apple silicon, and an Ollama server that the Mac can reach, because Ollama is not bundled. The GitHub download is free; the Mac App Store version costs $1.99, adds automatic updates and runs on iOS, iPadOS and visionOS. Image generation through Ollama was beta as of May 2026 and needs an Apple silicon Ollama server. The author states that generative AI helped write the code, so bugs are possible.
