LibreSprite is for drawing pixel art sprites and animating them frame by frame. A sprite is built from layers and frames, the animation previews in real time, and onion skinning shows the neighbouring frames.

- Several sprites can be open and edited at the same time.
- Palettes come ready made, or you can build your own.
- A tiled drawing mode helps with patterns and textures.
- Pixel-precise tools include filled contour, polygon and a shading mode.

A scripting API extends the editor. Version 1.2 added more script functions and example scripts, among them Voxel.js, which renders a sprite's layers as a 3D object and exports an STL file. The same release brought preliminary machine translations of the interface into eleven languages besides English, without right-to-left support. Themes for the interface are available from the project's resources repository. Release 1.3 offers separate disk images for Apple silicon and Intel Macs, alongside builds for Windows and Linux.

LibreSprite started as a fork of Aseprite, made at the last Aseprite commit covered by GPL version 2, and has been developed separately since. Aseprite's own site sells the program, with a trial version, and lists features such as RotSprite rotation, texture atlases and a command-line interface for asset pipelines. LibreSprite is free under GPL-2.0.
