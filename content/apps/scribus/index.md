Scribus places text frames and images on pages for brochures, newsletters, magazines and other print work, then exports a PDF a print shop can take. You draw frames, link them so text runs from one to the next, and control color and type yourself.

Scribus was the first desktop publishing program to support PDF/X-3. It also exports PDF/X-1a and PDF/X-4, and it can also make PDF forms and presentations. Colors can be RGB, CMYK, LAB, spectral or spot, with color management throughout. Nearly 200 palettes ship with the app, and you can preview pages as people with color blindness would see them.

Text supports right-to-left scripts such as Arabic and Hebrew, mixed-direction lines, Indic scripts and OpenType features. Documents are stored as XML. If a file gets damaged, you can open it in a text editor and repair it.

The stable release is 1.6.7. Its Intel disk image needs macOS 12, and the Apple silicon one needs macOS 13. Development builds of 1.7 are offered separately, and downloads are hosted on SourceForge. The official source sits in the project's Subversion repository, which GitHub mirrors.

Affinity, from Canva, puts page layout in one app with photo editing and graphic design. Scribus handles layout alone, under the GPL, and its files stay readable.
