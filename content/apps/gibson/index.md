Gibson is a screen saver that fills the display with a security operations dashboard in the style of hacker films: a process table, CPU per core, memory, disk, network, a radar, a globe and a file vault, among others. It suits people who want an idle screen that looks like a film prop, including in an office. The README separates what is read from the Mac (process table, CPU, memory, disk, network, host details) from what is invented for the look (the user account table, the file manager grid, the session log and the radar and globe contacts). It can mask host name, user and addresses, and it can switch off live readings altogether.

The README says it needs macOS 14 or later and is a universal bundle for Apple silicon and Intel. Releases are Developer ID signed and notarized, so the download opens without a security warning. The manual install places it in your Screen Savers folder. The README says nothing leaves the machine, and it writes only the screen saver's own preferences.
