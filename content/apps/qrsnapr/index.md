QrSnapr is a menu bar utility that turns QR code images into web addresses. It decodes the code and copies the resulting URL to the clipboard, so you can paste the link instead of scanning the code with a phone. It suits people who receive QR codes as image files and want the link itself.

It requires macOS 13.5 or later. The release provides separate Apple silicon and Intel zip files. The build is not signed or notarized, so the first launch has to be allowed: right-click the app, choose Open, and confirm. The latest release, v1.0.0, dates from April 2025.
