SidebarFavorites gives each folder in Finder's sidebar the icon you choose, either an SF Symbol or an SVG you import. It works for local folders, iCloud Drive, cloud-provider folders, mounted disks and network shares. The icons persist without the app running, because a small helper bundle does the work; you only open the app to add, edit or remove favorites. Folders that already have an icon of their own can keep it through an optional "Both icons" mode.

It requires macOS 13 or later on Apple silicon and Intel. The DMG is Developer ID signed, notarized and stapled. "Both icons" mode adds a Finder Sync helper of about 6 MB for each favorite that uses it. Sidebar icons are always monochrome, which is a macOS rule rather than a limit of the app.
