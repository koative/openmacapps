ScreenCut captures the whole screen or a selected area and lets you mark it up with rectangles, ellipses, arrows, freehand strokes and text, with adjustable font size, line thickness and colours. Its OCR reads the text inside a selected area so it can be copied. Translation runs through a large language model endpoint that you configure yourself. It suits developers and designers who annotate screenshots for bug reports or documentation.

It requires macOS 15 or later; the README says it was built for macOS 15 and other versions need more testing. The DMG is ad-hoc signed and not notarized, so the first launch has to be allowed in System Settings. The latest release dates from December 2024.
