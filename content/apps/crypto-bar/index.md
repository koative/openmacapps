Crypto Bar sits in the menu bar and shows cryptocurrency prices, kept current over a live connection to CryptoCompare. The primary currency pair appears in the tray. It is built with Electron and React, and its last release, 1.1.16, dates from January 2018.

The README says the author has stopped maintaining the project, so treat it as a finished tool that will not receive fixes. The upstream README does not state a macOS version, and this entry does not claim one.
