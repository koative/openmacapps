Iconizer creates the folder structure of an Xcode asset catalog and fills it with App Icon, launch image and image set files generated from one source image. It is for developers who would otherwise export each size by hand.

The 2020.11.0 DMG is a universal build with a minimum of macOS 10.10. It is not code-signed or notarized, so macOS blocks the first launch. Allow it in System Settings under Privacy & Security. The last release is from November 2020, and the last commit from October 2021.
