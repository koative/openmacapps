Koru is a workspace for writing and notes that keeps documents, files and terminal sessions in tabs, including your shells and coding agents such as Claude Code and Codex. Documents support headings, tables, checklists, tags and named versions, and you can import from Evernote, Notion and Markdown. Devices sync directly with each other over an end-to-end encrypted connection, so the data stays on your own devices. It suits people who want their notes to stay off cloud servers.

It requires an Apple silicon Mac running macOS 12 or later, according to the README. The README says the macOS disk image is signed and notarized. The project is pre-1.0: the first public release shows documents, files and terminal sessions, while tasks, the AI chat and canvases sit behind feature flags that official builds may leave off. Usage telemetry is opt-in.
