Heroic signs in to your Epic Games, GOG and Amazon Games accounts and lists the games you own there in one library. From that library you install a game, launch it, and later update, repair, move or uninstall it.

- Epic games go through Legendary, GOG games through Heroic's own gogdl, and Amazon games through Nile.
- An existing Epic Games Store installation can be synced, and games already on disk can be imported.
- Save files sync with the cloud.
- A download queue handles several installs in turn.
- Games and apps from outside the three stores can be added to the library and sorted into your own categories.

On the Mac, Windows games run through CrossOver. Epic games with online play run too, but games with anti-cheat work on macOS only when the game allows it. The stores themselves are reachable from inside Heroic.

Heroic needs macOS 14 or later. The download page has separate builds for Apple silicon and Intel Macs, offered as DMG and ZIP on the releases page. The interface comes in close to 40 languages and takes custom themes.
