littleguys is a WhatsApp-style chat window for AI agents. Each agent, including OpenClaw, Hermes, Claude Code, Codex and any ACP-compatible agent, appears as a contact with its own threads. A small character in the menu bar shows whether an agent is idle, working, has a new reply or needs you. The app can approve or deny commands, run scheduled routines, and pair an iPhone app with the Mac. It suits people who already run coding or OpenClaw agents and want one place to talk to them. Hermes, Claude Code and Codex work without OpenClaw.

It needs macOS 13 or later and is a universal build for Apple silicon and Intel. The project says each release is signed and notarized. It has no accounts and no telemetry; its outside requests are its own updates from GitHub, the ACP agent list when you add an agent, and phone notifications through its relay. Clicking a notification does not open its thread yet.
