ClipAI keeps a searchable history of what you copy and shows previews of text, images and code with syntax highlighting. Any item can be sent to OpenAI or Google Gemini with a built-in prompt, such as a code review, a JIRA ticket draft or a rewrite, or with a prompt you write yourself. Global hotkeys open the history or run a prompt. It suits people who copy text into AI tools many times a day and would rather act on the clipboard from the menu bar.

The release DMG is a universal build for Apple silicon and Intel. Its Info.plist sets macOS 15.2 as the minimum version. It is signed with a Developer ID certificate and notarized, so it opens without a Gatekeeper override. AI features need your own API key for OpenAI or Gemini, and the README does not describe any other account or service.
