Menubar Brightness puts a screen brightness control in the Mac menu bar. Its preferences window, opened with Command-comma, lets you choose whether the app starts at login, and it can quit the app. The project is a small MIT-licensed utility, and its README thanks the Kap project for its source code.

The README says the app is for macOS only and gives no minimum macOS version. It does not say whether the download is notarized, so check the signing status yourself before the first launch. The project's last release is version 0.0.2 from November 2017, and its last commit is from the same month, so it is unmaintained and may not behave as expected on current macOS releases.
