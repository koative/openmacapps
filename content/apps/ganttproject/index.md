GanttProject plans projects on a Gantt chart. You build a task hierarchy, link tasks with dependencies, mark milestones, assign people and see their workload on a resource chart, and compare progress against saved baselines. It can also generate a PERT chart and calculate task costs.

Projects can be exported to PDF, HTML and PNG, and exchanged with Microsoft Project and spreadsheet apps. Files can be shared over WebDAV, and the developers also run a separate paid collaboration service, GanttProject Cloud; the desktop app itself is free.

macOS builds come as separate DMGs for Apple silicon and Intel. The latest stable release is 3.3 from January 2024; a 3.4 beta is available as a pre-release.
