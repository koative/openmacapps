GifCapture records the area of the screen that you drag and resize. Cmd+R starts a recording, and Cmd+S stops it and saves an animated GIF. It suits short looping demos and bug reports. The README lists a progress display and multi-screen capture as unfinished.

The release contains an x86_64 binary only, with a minimum of macOS 10.11. The app is not signed and not notarized, so macOS blocks the first launch. Allow it in System Settings under Privacy & Security. The last release is from June 2017, and the last commit from April 2021.
