Barista is a menu bar switch for macOS's built-in `caffeinate` command. Turn it on to keep the system or the display awake, and turn it off to let the Mac sleep again. You choose which `caffeinate` options apply, and it can switch on automatically when it starts. It suits people who want `caffeinate` without a terminal, although it does not expose every `caffeinate` option.

It requires macOS 13.6 or later and is a universal build. The DMG is not notarized and carries only an ad-hoc signature, so macOS blocks the first launch and you need to allow it in System Settings.
