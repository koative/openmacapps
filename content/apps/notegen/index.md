NoteGen lets you save a thought, voice recording, screenshot, link, file or todo the moment it turns up, and sort it out later. Filter those records by tag, time or type, pick the ones that belong together, and have them organized into a Markdown summary, report or article that you then edit yourself.

Notes stay ordinary Markdown files in a workspace folder you choose, so another editor or Git can open them too. The editor handles:

- tables, task lists, code blocks, math and diagrams
- a source mode next to visual editing
- attachments, file references and file history
- a canvas for flowcharts, mind maps, timelines and freehand drawing

AI features work only after you configure a provider and model; you can pick different models for chat, writing, OCR, image recognition and audio. Beyond organizing records, they rewrite or translate text, answer questions from a knowledge base built from your files, and connect to MCP servers.

Sync is optional. It can go through GitHub, GitLab, Gitee, Gitea, S3-compatible storage or WebDAV, and local backups work without any of them. The download page states that no account is required.

The desktop builds are labelled beta. GitHub releases carry separate DMGs for Apple silicon and Intel. The download page gives a Terminal command for when macOS calls the app damaged.
