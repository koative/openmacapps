ClipPocket keeps a searchable history of everything you copy. It recognises item types such as URLs, colours, code, files and images, and lets you pin the items you use most. It opens from a menu bar icon or with ⌘⇧V, and it can paste the selected item straight into the frontmost app. The history stays on your Mac, since the project has no cloud sync or external servers.

The README lists macOS 13.5 or later on Apple silicon or Intel. The DMG is ad-hoc signed and not notarized, so the first launch has to be allowed in System Settings.
