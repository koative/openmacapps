Oh My Android is a native SwiftUI control panel for the Android Emulator, and for real phones over adb. It replaces typing adb commands with switches for dark mode, font scale, RTL and locale, TalkBack, network throttling and GPS mocking, and adds screenshots, screen recording, a Layout Inspector that reports sizes in dp, a TalkBack-order accessibility audit and a SharedPreferences/SQLite inspector.

It also ships a stdio MCP server with 18 tools, so AI coding agents such as Claude Code, Codex, Cursor and VS Code can see and drive the emulator. Requires macOS 26 Tahoe or later; the app is signed and notarized.
