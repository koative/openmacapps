Dockit is a macOS window manager built around the screen edges. A keyboard shortcut docks a window to the left or right edge, where it stays out of the way until the pointer reaches that edge, and it goes back when the pointer leaves. Shortcuts can be customised and the app can start at login. It suits people who want a window tucked away but one hover from view.

The Apple silicon build declares macOS 13.5 or later. The README asks for Accessibility permission on first run. The release also lists an Intel DMG, which was not checked. The app is ad-hoc signed and not notarized, so macOS must be allowed to open it in System Settings before the first launch.
