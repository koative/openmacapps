Floorp takes Firefox and adds tools for arranging tabs and pages. Firefox stays underneath; on top come workspaces, split view and a sidebar for sites you check often.

- Workspaces group tabs by task and switch with one click, and Firefox containers can be tied to a workspace to keep cookies and sign-ins apart.
- Split view shows up to four pages in one window, each panel at the width you set.
- Web panels pin sites to the sidebar so they stay open beside the page you are reading.
- Mouse gestures, web apps in their own windows, and interface customization cover the rest.

No account is needed, and a built-in import tool brings data across from the browser you use now. An iOS version is in testing through TestFlight.

Floorp's own comparison table, dated July 2026, credits Vivaldi with split views and web panels as well, but rates its source code as only partly open. The same table marks Chrome as unable to show three or more pages side by side in a window. Floorp's code is fully open under the MPL 2.0, and it is free.

For the Mac, each release ships one Universal disk image for Apple silicon and Intel. It requires macOS 10.15 or later.
