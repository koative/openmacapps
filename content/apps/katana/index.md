Katana lives in the menu bar. It takes screenshots and uploads them to image hosts such as Imgur and Pomf-style services, accepts files dragged onto the menu bar icon, and can shorten links copied to the clipboard. Keyboard shortcuts and hosts are configurable.

The README does not state a macOS version, and signing status is not stated upstream; neither is claimed here. The 1.4.4 release from March 2019 removed some default hosts because they had gone offline, so check that the host you want still works.
