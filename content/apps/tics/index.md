TICS lives in the menu bar and plays a keyboard sound for every key you press, in any app. It includes eleven keyboard sound packs, from Cherry MX and Topre switches to a synthetic one generated in code, and you can give a group of keys, a single key or a shortcut its own pack. Mouse clicks, drags and scroll-wheel notches have their own pitch, volume and tone settings. It suits people who like the feel of a mechanical keyboard on a Mac and want the sound without the hardware. Logitech mice running Logi Options+ are supported through an optional tile.

It needs macOS 14 or later and works on Apple silicon and Intel Macs. The first launch asks for Input Monitoring, which it uses to tell which key was pressed; the README says it does not save what you type or where you click. It checks GitHub once a day for a new version unless you turn off Check for Updates. The Logitech option asks for Bluetooth permission. The README does not say whether the build is notarized.
