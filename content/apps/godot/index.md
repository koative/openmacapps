Godot is a full game engine whose editor is itself a desktop app. You build games as trees of nodes and scenes, write behaviour in GDScript, a Python-like language made for the engine, and preview the result straight from the editor. It covers 2D and 3D work, with physics, animation, UI, audio and shader tools, and it exports to desktop, mobile and the web.

The macOS download is a universal build for Apple silicon and Intel, code-signed and notarized. A separate .NET build adds C# scripting and needs the .NET SDK installed. Per the system requirements page, the Compatibility renderer runs on macOS 10.13 or later, the Vulkan-based Forward+ and Mobile renderers need macOS 10.15, and their Metal backend needs macOS 13.
