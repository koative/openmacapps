PasteBar records everything you copy in an unlimited history that you can search, and gives you a second space for clips you want to keep. Saved clips go into collections, tabs and boards, and each one can carry a note written in Markdown. Paste menus give quick access to them, and you can paste straight from the system menu.

- Text, images, files, links and code are all kept; code gets automatic language detection and syntax highlighting.
- A Quick Paste window starts searching as soon as you type.
- Collections can be locked behind a PIN, and the whole app behind a passcode.
- Forms and global templates are supported, along with web scraping and API data extraction.
- Backup and restore export the clip database together with its images.

Data is stored locally, and you can point PasteBar at a folder of your choice, such as a cloud drive, to share it between machines.

Paste also has pinboards and keeps its history in sync between Mac, iPhone and iPad. PasteBar runs on Mac and Windows, and syncing is left to whatever folder you store the data in.

Version 0.7.0 runs on macOS 10.13 or later. It comes as a Universal DMG or as separate Apple silicon and Intel builds; the app in the Universal DMG is Developer ID-signed and notarized.
