Human Eyes reads the sessions, memory notes, CLAUDE.md and AGENTS.md files, skills and MCP settings that Claude Code and Codex leave in your home folder, and shows them in one window. You can full-text search sessions, ask questions across your history with answers that cite their source sessions, find to-dos the agents left for later, audit memory notes for broken links and duplicates, and plan on a canvas. It suits developers who use coding agents daily and want to find past fixes. The AI features are opt-in and use the Claude or Codex CLI you already have, or Apple's on-device model.

It needs macOS 15 or later; Apple's on-device model needs macOS 26. The app is universal, running natively on Apple silicon and Intel. It is signed but not notarized by Apple, so the first launch has to be allowed: right-click the app and choose Open. The README describes the project as young and built by one person. It checks GitHub daily for new releases, which can be turned off, and has no telemetry.
