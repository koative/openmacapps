Itsypin lives in the menu bar and opens the websites you pin in a floating popover window or a small screen bubble, so a service can be checked without switching browsers. Pinned sites can also be opened with global keyboard shortcuts, which the README says need no Accessibility permission. It suits people who keep a few web tools open all day.

It requires macOS 13 or later. The release DMG is Developer ID signed and notarized, so it opens without the Gatekeeper workaround. The project is MIT licensed and has a README with build instructions for developers.
