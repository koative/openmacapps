MacState puts CPU usage and temperature, memory, fan speed, network speed and GPU load into a single menu bar item, so you can check a Mac's condition at a glance. Clicking the CPU, memory or network reading opens a list of the ten processes using the most of that resource, and an optional Finder right-click extension adds commands to open a terminal in a folder or copy its path. It suits people who want a compact readout without a heavy monitoring app.

It needs macOS 13 or later and runs on Intel and Apple silicon Macs. The settings window switches between Chinese and English, and it lets you change the refresh interval and turn each module on or off. The README does not say whether the release builds are notarized.
