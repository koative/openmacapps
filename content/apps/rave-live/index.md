RAVE LIVE is a light show for whatever your Mac is playing. It listens to the system audio, follows the beat, and drives Metal visuals and MilkDrop presets in time with the music, with optional synced lyrics on screen. It is built for a party, a room or a festival-style display rather than as a music player. It is free software under GPL-3.0, and the README notes that the name and icon are not covered by that license.

It runs on macOS 12 or later as a universal app for Apple silicon and Intel. Hearing system audio needs macOS 13 or later and Screen & System Audio Recording permission, which the app uses only to hear the sound, not to record the screen. On macOS 12 it takes input from a microphone, interface or loopback driver. Any Metal GPU works, and Intel or AMD graphics get lighter settings. The app is not notarized, so the first launch needs Open Anyway. The README says it has no account, analytics or telemetry, and it contacts lrclib.net only when the optional lyrics feature is on. It is Mac-only for now.
