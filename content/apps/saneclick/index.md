SaneClick puts extra commands in the Finder right-click menu, so you can convert a HEIC image, merge PDFs or copy a file's path without opening another app. It ships with 62 ready-made actions in five categories, and you switch on the ones you want from its library.

- Actions appear only for matching file types, and can be limited to a single file or to a range of selected items.
- Image tools convert, resize, strip metadata and pull text out of pictures with OCR.
- File actions hash files, create archives, clean up names and open the selection in Terminal.
- Custom actions run your own Bash script, AppleScript or Automator workflow, and a Test button previews the output on real files before you save.
- Custom scripts can be exported and imported as JSON.

SaneClick needs macOS 14 or later on Apple silicon. The download from GitHub or saneclick.com is notarized and runs as a 14-day trial, after which the app must be bought. A separate edition in the Mac App Store costs nothing and carries 13 actions, with 24 more behind an in-app purchase. Its source is published under PolyForm Shield 1.0.0, which bars using it to build a competing product.

The menu items come from a Finder extension that you enable in System Settings under Privacy & Security, Extensions. A status badge turns green when it is active and orange when Finder needs a restart, which the app can do for you. You also choose which folders SaneClick watches. The developer says file contents are never uploaded.
