Softfold folds the desktop away when a MacBook lid closes. The live screen tilts with the hinge, blurs from the top down and fades into the dark edges, then returns sharp when the lid opens. It is a menu bar app for people who want a little motion on their laptop. Softfold is forked from Hinge, and its license file keeps the Noveum.ai copyright line for that project.

The README asks for macOS 14 or later on an Apple silicon MacBook with a lid-angle sensor, and it lists which models have one. Softfold needs Screen Recording permission. The build is signed and notarized. It sends a daily anonymous usage heartbeat, which can be turned off in its window.
