iGlance puts a set of live stats in the menu bar: a CPU utilization graph, CPU temperature, memory use, network traffic and fan speed. You choose which items appear, and you can set thresholds for low and high battery notifications. The app adjusts to light and dark mode.

The app requires macOS 10.12 or later and the build is Intel only (x86_64). The build is notarized. The README says the project is no longer under active development. It also warns about an App Store app called iStats X, which it says copies an old version of iGlance and shows random temperature and fan values.
