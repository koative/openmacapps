ClaudeCodexBattery shows what remains of your Claude Code and Codex usage limits as battery icons in the menu bar. The dropdown lists each limit window with its reset time, and an optional cost breakdown uses ccusage. It suits people who use both agents and do not want to type /usage to check. A SwiftBar plugin with the same display is also available.

The README says the app is signed and notarized and needs no separate install. It reads your existing Claude Code and Codex logins to query Anthropic's and OpenAI's usage endpoints, and it checks GitHub once a day for updates. Claude limits need Claude Code logged in on the Mac. The README does not state a minimum macOS version.
