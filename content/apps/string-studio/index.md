String Studio opens Apple .xcstrings files and shows every language in an editable table. You can search, filter by translation state (new, translated, needs review or don't translate), and batch-translate selected strings with an AI service you configure using your own API key. The README says its translation prompts are tuned for Apple's design guidelines. It suits developers and translators who maintain Apple localization catalogs.

It needs macOS 15 or later and runs on Apple silicon and Intel. The app is notarized by Apple. The README also links an App Store listing.
