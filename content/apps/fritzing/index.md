Fritzing lets you build a circuit the way it looks on your desk. You drag parts from the library onto a virtual breadboard and wire them up, then continue in the schematic and PCB views. A finished board can be exported as Gerber files, and the project's Fritzing Fab service will manufacture it.

The parts library holds many common high-level components, and you can make and share your own. Fritzing is aimed at makers and hobbyists and keeps the barrier to entry low. Recent versions also simulate circuits. Release 1.0.8 fixed a crash in transient simulation and added a printer-friendly bill of materials.

The source code is GPL, the documentation and part graphics are under Creative Commons BY-SA 3.0, and the code lives on GitHub. Ready-made installers are sold on fritzing.org, and buying one funds further development. If you would rather not pay, you can build the app from source by following the developer instructions.

The macOS download is a Universal app for Apple silicon and Intel. Version 1.0.8 supports macOS 12 Monterey through macOS 26 Tahoe. Older Macs have their own last versions: 1.0.1 for Catalina, 0.9.10 for High Sierra and 0.9.3 for Sierra and El Capitan. Circuits you create are yours to use as you like. If you publish breadboard images, the project asks for a short credit.
