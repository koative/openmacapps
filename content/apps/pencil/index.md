You build wireframes in Pencil by dragging shapes from its stencil collections onto a page, then arranging and styling them on a vector canvas. A mockup can run to many pages, and any element can link to another page.

- Built-in collections cover desktop and web controls, Android and iOS screens, general shapes and flowchart elements.
- Connectors wire shapes together, so the same canvas works for flowcharts and other diagrams.
- More stencils install from the online repository under Tools > Manage Collections, from an archive URL or from a local ZIP.
- Exports include PNG images, PDF, Inkscape SVG, LibreOffice text documents and a web page. In the web export, links between pages become clickable, so viewers can step through the flow.

Pencil runs on macOS, Windows and Linux and saves documents as `.ep` or `.epz` files. The Mac download page offers separate DMGs for Apple silicon and Intel, plus a universal one.

Version 4.0 arrived in October 2026, nearly four years after 3.1.1, and adds an MCP server inside the app at `127.0.0.1:1919`. Settings > MCP copies ready-made configuration for Claude Desktop, Cursor, Antigravity and VS Code. A connected assistant can list the installed stencils, add and move shapes, create pages and request a rendered preview to inspect its own layout. The developers say documents and MCP traffic stay on the Mac.
