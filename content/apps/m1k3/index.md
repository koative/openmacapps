M1K3 is a local AI assistant for the Mac. Its language models run on the device, and it can answer questions, search your own notes and PDFs, keep dated memories, speak replies with an on-device voice, and share its knowledge with coding agents through a local MCP server. It suits people who want an assistant that keeps their documents and conversations on their own Mac.

It needs macOS 26 or later on Apple silicon. The DMG is signed with a Developer ID and notarized, so it opens without a Gatekeeper override. Web search is on by default and can be switched off, and the README says the DMG build has no cloud path. The download is a nightly build, and a bigger model is downloaded once when you ask for it. The Mac App Store build is a separate build.
