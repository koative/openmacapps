Mac System Data Cleaner scans for the part of macOS storage counted as System Data, such as caches, hidden files and leftovers from apps you no longer use. You can search and look through the results, and an unfamiliar file name can be checked with a web search before you act. Selected files can be moved to the Trash instead of being deleted at once. It suits people whose drive fills with System Data and who want to see what is taking the space before anything is removed.

It needs macOS 12.4 or later and runs on Apple silicon and Intel. The app is notarized by Apple. The README is short and asks users to research unknown files before deleting them, and to rely on the Trash until they are sure.
