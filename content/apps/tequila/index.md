Tequila is a personal workspace for macOS that puts six everyday tools in one window. Focus holds the day's tasks and priorities, with weekly recurring plans and separate progress for each selected date. Timer offers count-up and countdown timing, Calendar shows the schedule, Mail brings several email accounts together, and Logs keeps notes and research. Settings covers the interface. It is built with Swift, SwiftUI and AppKit, and the project describes it as an independent effort rather than a company product.

The app bundle declares macOS 15.2 or later. The download is not notarized by Apple, so macOS may block the first launch; the README asks users to check the source before allowing it under System Settings > Privacy & Security. The README does not state a minimum macOS version, and the requirement above comes from the app bundle itself.
