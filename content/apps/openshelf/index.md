OpenShelf is a menu-bar utility for acting on a file while you are still dragging it. Start a drag and tap a key, and a wheel appears under the pointer. Drop the file on a wedge to convert it, crop, compress, run OCR, redact it or edit its metadata, or to AirDrop, copy, move or shelve it. Converted files are saved next to the original. It suits people who handle many small file jobs and do not want to open a separate app for each one.

It needs macOS 14 Sonoma or later. The README says it runs on Apple silicon, and on Intel Macs up to macOS 26. The app is not notarized by Apple yet, so the first launch has to be allowed in System Settings under Privacy & Security. Extra converters such as ffmpeg and LibreOffice are optional downloads. The only other network access is the update check against GitHub, which can be turned off. The project says it collects no telemetry.
