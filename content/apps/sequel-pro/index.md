Sequel Pro is a native Mac client for MySQL and MariaDB databases. It is the original project that Sequel Ace, also listed in this catalog, continues. The MIT-licensed code is on GitHub, and the release files are attached to GitHub releases.

The last release, 1.1.2, is from April 2016, and the default branch has had no commits since July 2020. The project's website did not resolve when this entry was checked, so the repository is used as the link. The app inside the release disk image declares macOS 10.6 as its minimum and is Developer ID signed and notarized.
