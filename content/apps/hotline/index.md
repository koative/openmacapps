Hotline was a Mac suite from 1997 for running community servers with chat, private messages, threaded news, message boards and file libraries. This project remakes the client in SwiftUI for current macOS, so you can join existing Hotline servers from a modern Mac. It suits people who want to reach those communities again. The project does not include server software; the README points to the Mobius server project instead.

The README requires macOS 26 (Tahoe) or later. The current download is a beta build (1.0beta29), and iOS, iPadOS and visionOS versions are not released yet. The README does not say whether the build is notarized.
