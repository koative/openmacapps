NotchDial turns the MacBook notch into a switcher for AI coding agents such as Codex, Cursor and Claude. You hover the notch to switch to one of these apps in one of three display modes. While an agent works, its icon and a spinning ring appear beside the notch, and a green check appears when it finishes. It is aimed at people who use these agents on a notched MacBook.

It requires a notched MacBook with Apple silicon and macOS 13 or later, and it needs Accessibility permission. The release zip is not notarized and is ad hoc signed, so the first launch has to be allowed in System Settings. The README also describes a status signal that can come from the agents' network activity.
