Fanny shows each fan's current, target, minimum and maximum speed, the number of fans, and the CPU and GPU temperatures. It runs as a Notification Center widget or as a menu bar app.

The 2.3.0 build is signed with a Developer ID and notarized, and its bundle sets macOS 10.13 as the minimum. The executable contains only x86_64 code, so the build is Intel-only.
