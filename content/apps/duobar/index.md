DuoBar puts three kinds of status into one menu bar glyph. An outer ring shows battery level on a MacBook, or adaptive CPU, memory and thermal pressure on a desktop Mac. The centre shows the active network, and four dots show the output volume. The popover adds a volume slider, output switching, Wi-Fi power control and live network speed, and an optional Dock icon is available. It suits people whose menu bar is crowded and who want these readings in one place.

It requires macOS 13 or later and runs on Apple silicon and Intel as a universal build. The 1.4.0 DMG is Developer ID signed and notarized. Volume control only works on outputs that expose software volume; HDMI, AirPlay and some USB outputs show "Controlled by device". The Wi-Fi name may need Location permission, and AirPods detection is best effort. The README says the app has no analytics or telemetry.
