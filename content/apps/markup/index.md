Markup opens a folder of `.md` files and shows each note as a rendered page. Press E to edit in place, or use the raw-source shortcut to see the Markdown itself. It has a file tree, wikilinks, backlinks, a graph view and full-text search across a vault, and it exports notes to HTML or PDF with syntax-highlighted code, KaTeX math and Mermaid diagrams. It is for people who read and write a lot of Markdown and want a Typora-style writing feel without a paid license.

Apple silicon and Intel DMGs are published, and the README says the app is signed with an Apple Developer ID and notarized by Apple. The README does not state a minimum macOS version. The project is pre-1.0 and macOS only. It is built with Tauri on the system web view rather than in Swift, and the README says it has no account and no telemetry.
