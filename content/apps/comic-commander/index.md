Comic Commander browses comic and book collections on your disk. It shows each comic archive with a cover thumbnail, for CBZ, CBR, CB7 and CBT files, and opens those and PDF files in a built-in reader with zoom and rotation. PDF files have no cover thumbnails yet. It scans folders without writing into them and can import the category settings of the older Comic Commander server. It suits people with a large local library who want a desktop browser for it. The same app is built for Windows and Linux.

The release ships one universal DMG for Apple silicon and Intel; the README does not give a minimum macOS version. The builds are not signed, so the first launch has to be allowed in System Settings under Privacy & Security. The README describes the app as a rewrite that is still in progress and says PDF covers are planned for a later step, so expect rough edges.
