Tapflow lives in the menu bar and serves a page that a tablet can open in any browser on the same Wi-Fi network. You build the panels in a web editor on the Mac, with buttons, pads and window-snapping controls, and each touch is sent to the Mac and injected as keyboard or mouse input. It is for people who want frequent shortcuts, window moves and Dock actions on a tablet placed beside the keyboard. The project describes v1 as an early-access release.

The README requires macOS 15 or later on Apple silicon; its badge reads "macOS 15+ ARM64". The DMG is Developer ID signed but not notarized, so the first launch has to be allowed under System Settings → Privacy & Security. Tapflow needs Accessibility and Screen Recording permission, and the Mac side is macOS only.
