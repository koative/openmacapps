Perch reads the session files that Claude Code, Codex, OpenCode, pi and Cursor keep on your Mac. With live status turned on, it shows which sessions have finished or need your approval, lists those that need you first, and lets you allow or deny a command from the notch, answer some agent questions, and jump back to the exact session. It suits developers who run several coding agents at once and would otherwise keep checking terminals.

It requires macOS 15 Sequoia or later on Apple silicon; a notch is optional. The release is signed and notarized by Apple, so it opens normally once copied to Applications. There is no account, analytics or telemetry. Perch goes online to check for updates and to send feedback when you choose to, and it reads project folders only after macOS asks for permission for each folder.
