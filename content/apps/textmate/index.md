TextMate edits code and structured text, and its support for languages, markup systems and workflows comes from bundles. You install more bundles from Preferences, under Bundles.

- Multiple carets let you change several places at once or swap pieces of code.
- Snippets carry placeholders and transformations, so a stored piece of text adapts to the context where you insert it.
- Commands are scripts in any language that reads stdin, writes stdout and uses environment variables.
- Macros can be saved for reuse, or recorded once as a scratch macro and replayed straight away.
- File search shows matches in a list you can step through, extract text from or preview replacements in.

Scoped settings attach key shortcuts and settings to a scope selector, which helps when one file mixes languages, a project uses its own build system or third-party code has different formatting. Settings can also go in a `.tm_properties` file, in your home folder or at the root of a project. The file browser marks files changed under version control, and you can open a diff of the current file or commit a subset of changes. Clipboard history, themes, code folding and a live HTML and Markdown preview are built in.

TextMate 2.0.23 is a Universal app for Apple silicon and Intel that needs macOS 10.12 or later. It is Developer ID-signed and notarized.
