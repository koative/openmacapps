nCompHunt gathers open competitions from public sources into one native list: competitive programming rounds, AI challenges, CTFs, hackathons and design contests, with a focus on Vietnam as well as global events. You can filter by category and region, sort by deadline, get a notification for new finds, and optionally sync deadlines into a dedicated Apple Calendar. It suits people who follow contests and want their deadlines in one place. There is no account. Some sources need a free API key that you enter yourself; the keyless sources work out of the box.

It requires macOS 26 or later. The Mac App Store build is free. The direct DMG from the releases page is signed with a Developer ID and notarized by Apple, so macOS asks you once to confirm opening it; the App Store build skips that prompt.
