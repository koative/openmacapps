Write and annotate an OpenBoard lesson with a pen tablet, an interactive whiteboard or a mouse. You can present on the whiteboard, use a pen display beside a projector, or work on a plain computer screen.

In Documents mode, page thumbnails can be dragged to reorder them, and pages can be duplicated. You can import PDFs and images, including WebP, and export a document as a PDF.

The current release, 1.7.7, supports macOS 12 or later on Intel and Apple silicon and ships as a single disk image. Older versions for systems such as macOS 10.12 stay on the GitHub releases page. There is no registration step. Community translators have brought the interface to 35 languages.

The code descends from Open-Sankoré 2.0, which grew out of Uniboard, software the University of Lausanne first wrote in 2003. The Education Department of the canton of Geneva now maintains OpenBoard, which is licensed under GPLv3 with a linking exception for OpenSSL.

Web widgets are small websites placed directly on the board. OpenBoard includes a web inspector for debugging them, and the project wiki explains how to turn an existing site into a widget.
