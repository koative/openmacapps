Everest rewrites or proofreads text you have selected in many Mac apps. You press Option-R to rewrite, or Option-Shift-R to choose one of six styles (proofread, professional, friendly, concise, expand or simplify), check the result in a small panel, and press Return to replace the selection. It suits people who write in many apps and do not want to paste text into a chat window. The README says the built-in models run on the Mac, with no account and no telemetry, and work offline once downloaded.

It requires macOS 15 or later. The app is signed with a Developer ID and notarized by Apple. On first run it asks for Accessibility permission and then downloads a rewrite model of about 2.3 GB, which is not bundled. The app is MIT licensed, but the README says the model weights carry a separate Apache-2.0 license. Automatic update checks are on by default through Sparkle.
