Cluxo is a menu bar helper for presenters, screencasters and pair programmers. It highlights the cursor, offers a radial menu and on-screen drawing tools, shows keystrokes on screen, and includes a spotlight and a magnifier. The README is written in Korean, with an English version alongside it.

Requires macOS 13.0 or later. Grant Accessibility and Input Monitoring in System Settings; Screen Recording is optional and only the magnifier uses it. The release zip is not notarized, so the first launch needs Open from the right-click menu, or removing the quarantine flag with `xattr`, as the README shows. The README describes the current build as Apple silicon only, but the zip contains both arm64 and x86_64 code.
