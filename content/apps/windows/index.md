Windows is a small window manager that lives in the menu bar with no Dock icon. The front window moves by shortcut: left or right half, top or bottom half, full screen without covering the menu bar and Dock, centre, the next display, and sizes you define yourself. Dragging a window to a screen edge or corner snaps it, with an outline showing where it will land. Every shortcut can be changed, and the app warns when one clashes with a macOS shortcut, an open app's menu or another running window manager. It is deliberately smaller than Rectangle or Magnet, for people who want only the basics.

Requires macOS 14 or later on Apple silicon and the Accessibility permission, which macOS requires for moving other apps' windows. The app contains no network code. The README says the disk image is signed with Developer ID and notarized by Apple. The name is the maker's mark, so a fork should use its own name, and the project says it is not affiliated with Microsoft Windows.
