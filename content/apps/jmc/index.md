jmc is an open-source music manager and player for macOS, written in Swift. It is meant as a replacement for Music.app for people with large libraries: its keyboard controls stay consistent, and it tracks album artwork, PDFs, logs and cue sheets alongside the music. It also works with Apple Music and iCloud Music Library, and nearby jmc clients can stream music from each other over the network.

The README says jmc runs on macOS 10.15 or later and can be built from source. The download on the releases page is a beta, v0.3-beta, and the README does not describe notarization. The last commit is from August 2022.
