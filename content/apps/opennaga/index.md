OpenNaga remaps the 12 side buttons and extra controls of the Razer Naga V2 HyperSpeed, a mouse that Razer Synapse does not support on the Mac. It also sets DPI and polling rate, offers a Hypershift layer for a second set of actions, and switches button assignments when a different app comes to the front. Profiles can be written into the mouse itself so they keep working without the app running. It is for people who want to keep using this mouse on a Mac without Razer's software.

The DMG contains an Apple Silicon build that needs macOS 13 or later; Intel Macs have to build from source. The release is not notarized, so on first launch right-click the app and choose Open, or clear the quarantine flag as the README describes. OpenNaga asks for Accessibility and Input Monitoring permission, and saving a profile to the mouse needs the HyperSpeed USB receiver connected. The project began as a fork of NagaController.
