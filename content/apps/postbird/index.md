Postbird connects to PostgreSQL servers and lets you browse databases and tables, inspect table structure, edit row values, run queries in a query tab and save results as CSV. It is built with Electron and ships for macOS, Linux and Windows. It suits developers who only need PostgreSQL and want a small client rather than a tool that covers many database engines.

The README says the macOS download requires macOS 10.9 or later. The latest release, 0.8.4, dates from November 2019, although commits on the master branch continued until June 2025. The release notes advise right-clicking the app and choosing Open on first launch to get past the macOS warning.
