AI Gist keeps your prompt library on your Mac. A template uses placeholders such as {{name}}, you fill in the values when you use it, and copying the result records it in the history. A model you configure can generate prompts, rewrite them or extract variables. The README names Ollama and LM Studio for local models and OpenAI and DeepSeek for hosted ones. Data can be backed up to WebDAV or iCloud and exported as CSV. It suits people who reuse prompts across chat and coding tools.

The README says data stays local by default and that AI features need a model added in the app. It lists Apple silicon and Intel macOS builds, and says signed and notarized builds open directly, while older unsigned builds need an xattr command in Terminal. The project also ships for Windows, Linux, Android and iOS.
