CRTerminal (the README calls it crterm) is a terminal emulator with a vertical tab rail showing live titles and bell badges, a search palette over every session, and command history search that works with zsh shell integration. Sessions can be split or torn off into their own windows, and links and paths can be opened with ⌘-click. An optional CRT mode and retro themes change the look. It is for developers who keep many sessions open and want a fast, keyboard-driven terminal. Rendering runs on Metal.

It requires macOS 26 (Tahoe) or later on Apple silicon; the README lists no Intel build. The release is signed and notarised, and it updates itself through Sparkle. The code is licensed under Apache 2.0, and the README gives no extra terms.
