CAM is a minimal camera recorder for macOS. It records video from a camera and saves each clip as an .mp4 through a bundled ffmpeg binary. Each file name is built from the subject, session and task IDs you enter, plus a date stamp. It suits quick, simple recording sessions rather than editing.

The download is an Intel (x64) build from 2018. The repository has no README, so no macOS version or other requirements are documented, and the project has had no commit since October 2018.
