GitAhead is a graphical Git client for reading a repository's history, comparing diffs and working with commits. It is built on libgit2 and Qt, and it suits developers who prefer a visual history view to the command line.

The README says GitAhead is no longer under active development. Bug-fix releases will come as needed, and the README suggests a rebranded fork for anything beyond trivial changes. The latest release, 2.7.1, is from December 2023. For a source build on macOS, the README recommends Xcode 10.1 or later.
