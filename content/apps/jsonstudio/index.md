JsonStudio is a desktop app for working with JSON on your own machine. You can prettify and edit documents in a tree or grid view, compare them, validate against a schema, convert between formats and extract JSON objects from mixed log text. It also handles JSONL/NDJSON and JSON5-style input. It suits developers who work with API responses and logs. The README says the data stays on your machine and the app works offline.

The Apple silicon DMG's app declares macOS 10.13 or later; the release also publishes an Intel DMG, which was not checked. The builds are not notarized by Apple, so the first launch may need approval under System Settings, then Privacy & Security.
