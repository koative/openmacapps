Strata Files is a Finder replacement built for keyboard use. It searches your files as you type and accepts plain-English queries, shows folder sizes as soon as a folder opens, and maps disk usage as a treemap. It can show two folders side by side and compare or sync them, and it previews code, Markdown, archives, CSV and SQLite files. It also shows Git status and offers project cleanup. It suits people who manage many files and want speed and insight into what takes up space.

The app requires macOS 26 or later on Apple silicon. The DMG's app is signed and notarized by Apple. It goes online only to check for updates and to reach servers you connect to. Summaries and some Ask Strata requests use Apple Intelligence when it is available, and the README recommends granting Full Disk Access so that searches cover every folder.
