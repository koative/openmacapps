Beekeeper Studio Community connects to a database, lists its tables and lets you write SQL in tabs with autocomplete and syntax highlighting. Table data opens in a grid you can sort and filter, or as JSON.

- Saved queries and a query history keep earlier SQL at hand.
- Import, export, backup and restore move data in and out.
- Community connects to PostgreSQL, MySQL, MariaDB, SQLite, SQL Server, Redshift, CockroachDB, TiDB, BigQuery, Redis and GreengageDB.
- Oracle, MongoDB, Cassandra, ClickHouse, DuckDB, Snowflake and several other databases need a paid edition.

The download needs no sign-up or registration. It is a single app, and paid features unlock inside it with a license. Most of the repository is licensed GPLv3 or later, while the paid code in the `src-commercial` folder sits under a separate commercial source-available license.

TablePlus also browses and edits relational and NoSQL databases and adds an iPhone and iPad version, but it is sold by license. Beekeeper Studio runs on Mac, Windows and Linux, and its Community edition can be read and rebuilt from source. The GitHub release has separate DMGs for Apple silicon and Intel.
