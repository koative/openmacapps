Codex Reset Watcher is an unofficial menu bar utility. It shows the weekly and 5-hour Codex usage that remains, the reset credits you have banked, and when they expire. It reads the Codex Desktop login already on your Mac. It is read-only: it does not redeem resets, change usage or send analytics. It suits people who want to decide when to use a reset.

The README asks for macOS 14 or later and a signed-in Codex Desktop. It says the release app is ad-hoc signed unless a notarized build is published, so the first launch may need a right-click on the app and Open. The app calls internal Codex endpoints that may change without notice, and the project is not affiliated with OpenAI.
