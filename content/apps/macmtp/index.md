macMTP shows your Mac's folders beside an Android phone's storage, connected over USB in File Transfer (MTP) mode. You can drag files in either direction, cut, copy and paste between the panes, choose internal storage or an SD card, and decide how conflicts are handled, for example by skipping files of the same size. It suits people who want a native replacement for Google's Android File Transfer.

Requires macOS 14.0 or later, on Apple silicon or Intel, with the phone set to File Transfer mode. Releases come as DMGs for Apple silicon, Intel and universal Macs. The app is not notarized: the README says Apple notarization is not claimed or attempted without Apple credentials, so first launch needs approval in System Settings. Crash and error reporting is on by default and can be turned off in Preferences; the README says reports redact local paths. Copying between two phone storages is not supported, and dragging phone files straight to Finder is not implemented.
