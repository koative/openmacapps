Dao Browser is a Chromium-based browser that keeps the page at the centre. It has a vertical, Arc-style tab sidebar with folders and favourites, a Spotlight-style command bar, picture-in-picture and split view. Its built-in agent can read, click, scroll and navigate the live page you are viewing, with an on-screen cursor and banner that show when it is in control, and it keeps a long-term memory of past work in SQLite. It suits people who want a sidebar layout and AI help on the page they are reading, on an open-source Chromium base.

It is published for Apple silicon Macs; the README gives no minimum macOS version, and a Windows build is published alongside the macOS one. The README does not say whether the macOS build is notarized. The code is BSD-3-Clause, while the Chromium base and third-party components keep their own licenses, and the branding is not licensed for derived products.
