Ardour records audio and MIDI on any number of tracks, then lets you edit and mix them. Add a track and press record, or import audio and MIDI from disk or from the Freesound library.

- Editing is non-linear, with unlimited undo, ripple modes for spoken-word work, and stretching, quantizing and crossfades.
- Plugins load in AudioUnit, LV2, VST2, VST3 and LADSPA formats, and any parameter can be automated or bound with MIDI Learn.
- Routing connects any input to any output, inside Ardour or to other programs, with sends, inserts and returns.
- Sync covers MIDI timecode, LTC, MIDI clock and MIDI Machine Control, and Mackie Control and OSC surfaces are supported.
- A video timeline shows frame thumbnails of an imported clip, for scoring and soundtrack editing.

Version 9.8 arrived in August 2026 with keys and scales. Ardour can now mark notes that fall outside the chosen key, and if you want, it stops you from drawing new ones.

The source code is free under GPL version 2 or later. Ready-to-run builds for macOS, Windows and Linux are paid. You pay once or subscribe, and a separate free demo copy can be requested. Builds carry no license keys and keep working if a subscription ends. Building from source on macOS is possible, though the project gives no help with it.

REAPER has one fully featured version, which you can evaluate for 60 days before buying a license. With Ardour, the payment is for the ready-made build. Compile the free code yourself and you skip it.
