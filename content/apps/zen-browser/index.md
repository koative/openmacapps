Zen keeps your tabs in a vertical sidebar and groups them into workspaces, so a work project and personal browsing stay in separate sets you switch between. Underneath runs Firefox: release 1.24.1b is built on Firefox 159.0.1.

- Workspaces hold separate collections of tabs.
- Compact Mode hides the tab bar until you need it.
- Glance switches quickly among the tabs you use most.
- Split View shows two tabs side by side. Select several tabs, right-click one and choose Split.

There is no horizontal tab strip. The project's FAQ calls the vertical layout a core design choice and has no plans to change it.

DRM-protected streaming does not play on macOS. Zen has no Widevine license yet, which rules out Netflix, Spotify, Disney+ and Apple Music in the browser. For looks, Zen Mods offers community themes and tweaks, and live CSS editing lets you change the interface yourself.

The macOS download is one universal disk image for Apple silicon and Intel. Release builds use a stable Firefox version, while the Twilight channel carries pre-release builds with experimental features. The download page still labels Zen as beta.

Arc also puts tabs in a sidebar organised into spaces, but it is built on Chromium, and The Browser Company shuts it down on 22 December 2026. Zen stays on Firefox's engine and is licensed under the MPL 2.0.
