WandelBar draws a blurred, tinted copy of your wallpaper behind the menu bar and sets that copy as the desktop wallpaper, so the menu bar looks different without changing your original image. You can start from a preset or adjust strength, shadows and textures, and choose one design for every desktop or a separate design for the current Space. It suits people on macOS Tahoe who want a customized menu bar.

Prebuilt releases are Apple silicon only; the README says no Intel release is currently provided. It runs on macOS 14 Sonoma or later, but the README warns that before Tahoe the system menu bar background cannot be disabled, so the app adds little there. The README says the build is signed with Developer ID and notarized. It has no accounts or analytics, and its optional Community Gallery downloads content from GitHub.
