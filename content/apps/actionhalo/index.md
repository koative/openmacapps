ActionHalo opens a circular menu over selected text. After you select text and release the mouse, the wheel appears: click a slice to run an action, or press again, drag to a slice and release. Built-in actions copy, cut, delete, search, translate, open links and reveal paths in Finder, and plugins can add URL, shell, AppleScript or key-combo actions. It suits people who select text often and want an action wheel instead of the context menu.

It needs macOS 12 or later and runs as a universal build for Apple silicon and Intel. The README says community builds are ad-hoc signed and not notarized, so macOS may block the first launch until you choose Open Anyway. It needs Accessibility permission to read text selections. Updates are signed with the project's own Ed25519 key rather than an Apple Developer ID.
