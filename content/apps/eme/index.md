EME is a Markdown editor for writing and previewing documents. You can show the editor, the preview or both, and a focus mode hides everything else while you write. It renders math formulas and exports Markdown to HTML or PDF. If you turn the option on, saved files can be synced to a GitHub Gist. It suits writers who want a simple editor for Markdown files.

The README does not state a macOS version requirement. The releases page offers a DMG build. The latest release is from July 2020, and the repository was last pushed in December 2022.
