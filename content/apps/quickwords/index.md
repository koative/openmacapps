Quickwords replaces a short typed trigger with a longer word, phrase or paragraph in any app, so you can type a few keys for a standard reply or sentence. It listens to global keyboard events to do this, and its README says it keeps only the last 20 keystrokes in memory and saves no typed data. Replacements need Accessibility access, as the README's FAQ explains.

The authors say they have abandoned the project, and the README discourages new use because it has not received security updates for a long time. It suggests Raycast and Espanso as alternatives. The README does not state a minimum macOS version. The last commit is from October 2022.
