MacNTop puts a live dashboard behind a menu bar icon: per-core CPU with sparklines, memory split into active, wired and compressed, network and disk speeds, and the top processes by CPU or memory. The dashboard can also detach into a floating window that stays on top. The look is a green-phosphor CRT with scanlines, and six themes include a light mode. The README says it runs entirely locally and collects no data. It suits people who want a quick view of a Mac's load in a retro style.

It requires macOS 14 or later. The 0.1.0 zip is Developer ID signed and notarized. It is distributed outside the App Store because it uses restricted APIs, and disk I/O monitoring needs IOKit access. The project is still at version 0.1.0.
