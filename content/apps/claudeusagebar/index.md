ClaudeUsageBar keeps your Claude.ai session and weekly usage limits in the menu bar, refreshes them every five minutes, and sends notifications at 25, 50, 75 and 90 percent of a limit. Pro subscribers also see weekly Sonnet usage. It suits people who run into Claude limits and want to see them without opening the settings page. The README says the app is not affiliated with Anthropic.

It requires macOS 12 or later and is a universal build for Apple silicon and Intel. The release DMG is Developer ID signed and notarized. Setup means copying the Cookie header of a claude.ai request from your browser's developer tools, so the app holds a session credential; the README says data stays on your Mac. The app uses claude.ai internal API endpoints, which the README warns may change without notice.
