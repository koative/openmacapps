Widelands hands you a clan that starts with nothing but a headquarters, and you grow it into a settlement by placing buildings and laying roads. Carriers walk every good along those roads from one building to the next, so the road layout decides how well wood, food, iron and gold move through the economy. You never steer single workers. You order a building and the builders come, or order an attack and soldiers march.

The game was inspired by The Settlers II. Its five tribes, Barbarians, Empire, Atlanteans, Frisians and Amazons, each run a different economy, and each has a tutorial campaign that teaches how it differs. Beyond the campaigns you can play against computer opponents, or with friends over the Internet or a LAN.

- Tutorials in the main menu walk you through the first steps.
- A map editor is included and can publish a single map online from its main menu.
- An add-on manager, added in version 1.1, installs community maps, campaigns, tribes, win conditions and interface themes.
- Naval warfare is available as an experimental feature.

Version 1.3.1, released on 22 February 2026, comes as separate disk images for Intel and Apple silicon Macs on macOS 12 or later, and it cannot share a network game with 1.3. A browser download of the Apple silicon image picks up a quarantine flag, so the project suggests fetching it with curl or clearing the flag with xattr. MacPorts also carries the game. The code is GPL v2 or later, and some assets use Creative Commons licenses.
