TunnelFlow manages SSH tunnels in one window. You define local, remote and dynamic SOCKS5 forwards, group them, drag them into order, and watch traffic and connection health. It can reconnect dropped tunnels, keeps a tray icon, and offers a compact mini mode. It suits people who keep several SSH port forwards open at once and want them organised instead of spread across terminal sessions. The interface is in English and Simplified Chinese.

The README is still close to a template: its badges point at placeholder repositories, and it does not state a minimum macOS version or say whether the build is notarized. It describes the app as built for macOS, Windows and Linux. Check the release page and the first-launch behaviour yourself before relying on it.
