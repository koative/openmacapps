Zettlr is built for writing in Markdown. You type in plain text, cite sources from your reference manager and export the finished text in the format your school or employer asks for.

- Citations come from Zotero, JabRef and other reference managers.
- Exports run through Pandoc and LaTeX, with Word and LaTeX templates.
- A full-text search looks through the contents of your files.
- Zettelkasten-style note management is supported for building a body of linked notes.
- Snippets insert recurring boilerplate, and custom CSS changes the look of the editor.

Some export profiles need a separate LaTeX installation, which the documentation explains how to set up. A short tutorial ships with the app for first-time users.

Typora is another Markdown editor, built around a live preview that hides the Markdown syntax, and it is paid after a 15-day free trial. Zettlr is free under the GPL v3.

The Mac version comes as two DMGs, one for Apple silicon and one for Intel. The interface is translated into more than a dozen languages. Development is funded by donations.
