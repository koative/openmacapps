Is It Private is a Safari App Extension. Its toolbar icon changes appearance when the current Safari window is in Private Browsing, which helps most in Dark Mode. The GitHub release is a zipped app that bundles the extension; unzip it and move it into Applications. The README also lists the app on the Mac App Store. It is for Safari users who want a clear visual cue for private windows.

The README gives no macOS version and does not say whether the GitHub build is notarized, so this entry states neither. Its privacy policy says the app neither stores nor transmits personal details and includes no advertising, tracking or analytics. The code is MIT licensed, and the README credits two Noun Project icons used in the app.
