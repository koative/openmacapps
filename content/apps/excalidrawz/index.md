ExcalidrawZ puts the Excalidraw whiteboard canvas inside an app for Mac, iPad and iPhone, so your sketches live as files you can find again. You draw with the same hand-drawn tools as on the web, and the app keeps each drawing in a library that you can group and sort.

- It opens and edits .excalidraw files, plus PNG and SVG exports that still contain editable Excalidraw data.
- File history saves checkpoints, so you can go back to an earlier version of a drawing.
- Drawings sync through iCloud, and you can also link folders on OneDrive, Dropbox, Google Drive or a WebDAV server.
- You can import PDFs and export images, editable files or vector PDFs.
- Locked files are encrypted on disk, checkpoints included. Touch ID or the Mac password unlocks them, and a recovery key serves as a fallback.

Live collaboration uses Excalidraw's own collaboration feature. On top of drawing, the app can insert LaTeX formulas and function graphs, turn Mermaid diagrams into editable shapes and act as an MCP server for local AI clients. Its built-in AI chat can read and edit the canvas and shows proposed changes before applying them. It uses an AI account with credits, and you can hide any file from it.

Version 2.5.1 comes as a DMG on GitHub. It holds a Universal app for Apple silicon and Intel that needs macOS 14 or later and is signed with a Developer ID and notarized. The same app is on the App Store. The Excalidraw core it uses is published as open source in the developer's own fork.
