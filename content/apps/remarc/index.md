Remarc runs from the menu bar so you can comment on whatever you are reviewing: a selected passage of text, a screenshot with arrows and blur, a web element through a companion Chrome extension, or a spoken note. Each comment keeps the context it was made in. A coding agent connected over MCP can read the comments, work through them and mark each one resolved, which suits anyone reviewing work done by Claude Code, Codex or another agent.

It requires macOS 14 or later according to the README, and voice-based Crit Mode needs macOS 26. Release builds are signed and notarized, and the app updates through Sparkle. Comments stay on your Mac unless you hand them to an agent or to a webhook you configure. The project says it has no accounts or telemetry.
