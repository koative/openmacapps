Strategr is a planner for time-boxing your day. You describe reusable strategies and place them on a day timeline, then move, resize or copy the sessions on it. The v0.1.0 macOS build can import events from Calendar and shows the total time spent on each activity.

The release DMG holds an Intel (x86_64) build that is notarized, so it opens without the first-launch override. The latest release is from 2020, but the repository has commits from September 2026. The README says building is supported only on macOS and that the code is being reworked.
