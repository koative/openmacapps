macOS sets a separate picture on each display; SpreadPaper treats them as one canvas. You drag and zoom a single image over a live copy of your display arrangement, optionally compensate for bezel widths, and it renders the matching slice for every screen.

Besides static wallpapers it builds light and dark pairs that follow the system appearance, and dynamic sets of up to 16 images on a time-of-day schedule, all saved as presets in a gallery. It is a native app for macOS 15 or later on Apple silicon and Intel. Builds are not signed with an Apple Developer ID, so the first launch has to be approved in System Settings.
