MenuBarUSB lists the USB devices connected to your Mac in the menu bar, so you can see what is plugged in at a glance. You can customize the list, and it keeps a record of device activity that you can review. The author also offers a separate analysis tool for logs exported from other Macs, which the README suggests for support work. The project says it shares no code with a paid App Store USB app that inspired it.

The README does not list a macOS version. The current download is a zip, and the app is not notarized: macOS reports that Apple could not verify it, so you must allow it under System Settings → Privacy & Security → Open Anyway.
