TactileBar puts common macOS settings in one menu bar panel: keep the Mac awake, toggle Dark Mode, hide desktop icons, mute the microphone, lock the screen, empty the Trash, or purge Xcode's DerivedData. Live gauges show CPU load, memory pressure and disk fill, and Bluetooth audio devices can be connected or disconnected in one click. An experimental radial ring opens your pinned switches at the cursor. It suits developers and power users who change these settings many times a day.

It needs macOS 14 or later. The release is ad-hoc signed and not notarized by Apple, so the DMG needs its quarantine attribute cleared, as the README describes; the Homebrew tap install does this for you. Some switches ask for Automation, Accessibility (for the keyboard lock) and Bluetooth permission the first time you use them. The project is GPL-3.0 licensed, and the README describes how to build it from source.
