Element puts you in Matrix rooms and direct chats from a desktop window. You sign in to an account on a Matrix homeserver, either one run by a provider or one you host yourself, and talk with people whose accounts live on other servers.

- Rooms hold team or group discussions, and you set who can access them.
- Messages are end-to-end encrypted by default, and search also works inside encrypted rooms on the desktop app.
- Voice and video calls work one to one or in groups.
- You verify your own devices and can revoke a lost or stolen one.

The Mac app wraps Element Web in Electron, and both live in the same repository, so the desktop and browser versions share one interface. The project's own support policy covers the latest Element Desktop release on macOS versions that Apple still updates. For iPhone and Android, the project recommends its newer Element X apps instead.

Slack describes itself as a work platform built around channels, connected apps and its Slackbot AI assistant. Element runs on the open Matrix standard, so you choose the server and can still reach people whose accounts live elsewhere.
