DBine connects to more than 130 SQL, NoSQL, analytical and cloud database services from one desktop window. Each connection gets a tree of databases and objects, a query editor with autocompletion and saved queries, a table designer, ER diagrams, schema compare, a server monitor and a profiler. It can import connections from DBeaver, DbGate, DataGrip and other tools, read passwords from the system keychain or a secret manager, and block everything except reads on connections you mark read-only. It suits developers who work across several engines and want a single client for them.

DBine is free, and the project says it will stay that way; donations are optional. It runs on Windows, macOS and Linux, and the macOS installers come in Apple silicon and Intel versions. The project says the macOS app is signed with an Apple Developer ID and notarized by Apple. The name DBine and the AddLayer logos are trademarks, so a fork has to use its own name, and redistributions must keep the NOTICE file.
