Corona Tracker shows confirmed COVID-19 cases, recoveries and deaths on a world map and in charts. You can search for countries and cities, compare trend lines from the 100th case onward, switch charts to a logarithmic scale and share stats or charts as images. The README credits Johns Hopkins CSSE, Germany's Robert Koch Institute and Austria's health ministry as data sources.

The macOS build is an Intel (x86_64) app that declares macOS 10.15 as its minimum, and Gatekeeper accepts it as notarized with a Developer ID signature. The project is unmaintained: the last release is version 1.7.2 from August 2020 and the last commit is from October 2020. The Homebrew cask for the app is marked deprecated as discontinued.
