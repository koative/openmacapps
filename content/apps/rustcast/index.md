RustCast is a popup launcher. A shortcut opens a search box that finds and opens apps and files, evaluates calculations and unit conversions, searches emoji, and shows clipboard history. It can also control Spotify, run custom shell scripts, and send a query to Google when it ends with a question mark. Its config lives in ~/.config/rustcast/config.toml. The author built it to avoid paying for Raycast.

The README says the project is no longer maintained and points to other launchers, including the closed-source Tuna. Commits from other contributors still appear into November 2026. The DMG is a notarized universal build for Apple silicon and Intel, with a minimum of macOS 13.0.
