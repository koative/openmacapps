iMonet opens a folder of images and lets you step through them with the arrow keys or a thumbnail strip. Animated GIF, APNG and WebP files play frame by frame, and zoom centres on the cursor, with Cmd-scroll or a trackpad pinch. You can rotate, print, copy or move an image to the Trash, and an info panel shows its pixel size, file size, format and date. It is written in SwiftUI and uses only Apple frameworks.

It needs macOS 15.6 or later on Apple silicon; the app's own minimum version is 15.6 even though the README says 15.0. The release app is notarized. The App Store listing also offers optional yearly and lifetime support purchases, while the GitHub download is free.
