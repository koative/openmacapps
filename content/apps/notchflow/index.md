NotchFlow grows the black notch at the top of the screen into a workspace. You drop files, links or text onto it to keep them on a shelf, with actions such as Extract Text, Merge PDFs or Compress. It follows Claude Code and Codex sessions through their official hooks and can allow or deny a permission request from the notch. It also shows CI runs, local builds, downloads, music and focus timers. Copy suggestions, such as a next step for a link or a colour, are off until you turn them on. It suits developers who run agents and builds and want them visible without keeping a window open.

It needs macOS 14.6 or later and runs natively on Apple silicon and Intel. The release is signed and notarized, so it opens like other apps. The project describes it as a developer preview. The README says there is no telemetry or account, and that the app makes network requests only when you add a GitHub repository or ask for a link's title. Clipboard history, screenshot handling and GitHub Actions are opt-in and need their own permissions; the GitHub token is kept in the Keychain.
