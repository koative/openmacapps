nodeScratchpad is a menu bar app that evaluates Node.js code snippets and shows the result, so you can try a line of JavaScript without opening a terminal. The README says it has syntax highlighting and needs Node.js installed and on your PATH. It suits developers who want a quick scratch area for small experiments.

The DMG is an Intel (x86_64) build with a minimum of macOS 10.11 according to its Info.plist, so Apple silicon Macs run it through Rosetta 2. It has no usable code signature and is not notarized, so macOS blocks the first launch until you allow it in System Settings; the README mentions the unidentified-developer warning. The last commit is from January 2020.
