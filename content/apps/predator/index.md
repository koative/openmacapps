Predator turns the Mac's screensaver into a clock drawn in the red alien glyphs of the countdown device from the Predator film. The README has a diagram showing how the symbols map to digits, so with a little practice you can read the time from them.

The settings are few. You can pick any colour for the glyphs, switch between a 12-hour clock with AM and PM and a 24-hour one, and hide some extra lines for a look closer to the film.

The download is a ZIP holding `Predator.saver`, a Universal bundle for Apple silicon and Intel that needs macOS 11.5 or newer. Double-clicking the file installs it. macOS then blocks it as coming from an unidentified developer, and the README walks you through allowing it with Open Anyway in the security settings. If macOS calls the file damaged instead, the developer suggests downloading it again with Safari. Quit and reopen System Settings after installing or updating so the new version loads.

To remove it, right-click Predator in the screensaver list and choose Delete Predator, or delete `Predator.saver` from a Screen Savers folder in Library. The latest release, 1.0.7, came out in May 2025.
