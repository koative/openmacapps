LockIn blocks distracting websites and apps on a weekly schedule that you set in advance. Blocking happens at the system level, so one session covers every browser and app without an extension. You can group sites into reusable block sets, import lists from a file, pasted text or a public blocklist URL, and the README says enforcement continues through quit, kill and reboot. It is for people who want a block to hold when they would otherwise switch it off.

It requires macOS 13 (Ventura) or later, on Apple silicon or Intel. The README offers a signed DMG and a Homebrew cask from a third-party tap, but it does not say whether the DMG is notarized. Caveats: by design there is no quick way to end a session early, so set schedules carefully. The README says the app collects no analytics, and its privacy policy is in PRIVACY.md.
