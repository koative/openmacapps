NeatEditor is a plain-text editor for notes, drafts and quick edits that do not need a full IDE. It opens on a blank document and starts quickly. It has tabs you can rename and reopen, opens files through Finder or drag and drop, and autosaves after a short pause. It reloads changes made by another editor, script or coding agent, keeps both versions when edits conflict, and never empties an existing file because the editor was cleared.

Requires macOS 26.0 or later, on Apple silicon or Intel. The README says the release DMG is signed and notarized. It is macOS only, with no Linux or Windows build.
