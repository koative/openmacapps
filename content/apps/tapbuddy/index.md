TapBuddy is a small desktop pet in a floating window that lifts its paws as you type and opens its mouth when you click. A right-click menu switches skins, and you can add your own skins as folders of PNG frames. It is meant for people who like a light, animated companion while they code or write.

Requires macOS 13 or later and Accessibility permission, which it needs to watch keyboard and mouse input. The v1.0.0 DMG is ad-hoc signed and not notarized, so the first launch must be allowed; the README describes removing the quarantine flag or using Open Anyway in Privacy & Security settings. The README is written in Chinese.
