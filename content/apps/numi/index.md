Numi is a calculator that blends math with text. You type expressions with currencies, units, time zones or numeral systems, use variables, and export the results. It suits people who run frequent conversions and quick calculations rather than a full spreadsheet.

The MIT license covers the source on GitHub. The website offers the Mac download without a payment step, and its current build is version 3.35. The repository's last commit is from July 2025.

The GitHub build, version 3.34, declares macOS 10.13 as its minimum and is Developer ID signed and notarized, so it opens without a Gatekeeper override.
