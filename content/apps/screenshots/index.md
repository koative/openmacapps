Screenshots captures an area, a window, the full screen or a long scrolling page, and can copy the text recognized in a region. It also records the screen to MP4 or GIF, and it lets you annotate a capture with arrows, blur, spotlight and crop, pin it above other windows, or drag it into another app. It is a menu bar app for people who want a free, open-source alternative to CleanShot X; the README notes the project is not affiliated with CleanShot X. Its code makes no network connections.

It requires macOS 14 or later on Apple silicon only, and microphone recording needs macOS 15. The release is signed with a Developer ID certificate and notarized by Apple, so it opens without a warning. On first run it asks for Screen & System Audio Recording permission; the welcome window reopens the app once the permission is on, because macOS applies it only to a fresh process.
