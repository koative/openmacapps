Prism Launcher keeps each Minecraft setup in its own instance. You create an instance, add mods or a modpack, and launch that setup.

Every instance has its own settings, mods and configuration, so a heavily modded pack and a plain game can exist side by side. Individual mods install and update from Modrinth and CurseForge inside the launcher, and it also installs and updates whole modpacks for you. You can manage more than one account.

The launcher is built with Qt and has no embedded web browser. You can customize its menu and switch to a custom theme.

Prism Launcher started as a fork of MultiMC and is not endorsed by that project. It is not affiliated with Mojang or Microsoft.

The macOS download is a ZIP or DMG holding a Universal app for Apple silicon and Intel, Developer ID-signed and notarized. Development builds of the latest code are offered too, and the project warns that they can be unstable. The launcher code is under GPL 3.0 only, and the logo and related artwork under CC BY-SA 4.0.
