Screenshoss picks up each new macOS screenshot, moves it off the Desktop, and keeps it in a shelf at the top, left or right edge of the screen. On a notched Mac the shelf opens from the notch. You can create folders, mark favorites, select several captures, copy, delete, and drag them into other apps. It suits people who take many screenshots and want the Desktop kept clear.

It needs macOS 13 or later and is a universal build for Apple silicon and Intel. The README says the release is signed with a Developer ID and notarized by Apple. The app has no account, cloud sync or analytics; its Sparkle updater reads the signed update feed from GitHub Releases.
