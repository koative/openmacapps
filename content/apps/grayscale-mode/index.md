Grayscale Mode puts the macOS grayscale display filter behind a menu bar icon. One click drains the color from your screen, on any display, and the next brings it back. Option-Command-G does the same from the keyboard, and you can change that shortcut.

You can also pick apps that should keep their color. Grayscale Mode then leaves the filter off for them.

Version 2.1.0, from April 2020, is the last release, and the repository has had no commit since September 2021. The download is a DMG with an Intel-only app, signed with a Developer ID and notarized, which asks for macOS 10.14 or later.
