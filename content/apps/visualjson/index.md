VisualJSON is a simple pretty-viewer for JSON on the Mac. It lays a document out with indentation so nested objects and arrays are easier to follow. It is aimed at developers who read JSON responses and files. The README points to the Mac App Store as the main way to get it.

The last GitHub release, v1.6.0 from December 2013, is a `.pkg` installer, and the project has not been updated since 2016. The installer's signing certificate has expired and Apple has not notarized it, so macOS must be allowed to open it in System Settings. Its compatibility with current macOS versions is unverified.
