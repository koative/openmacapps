Smotrite is a system monitor for Mac meant as a clearer alternative to Activity Monitor. Its widgets show CPU, memory, network, hardware, drive and CPU temperature readings, and the app also has a mini view. It suits people who want a quick overview of how the machine is doing.

The author describes the app as alpha: it was made over a weekend, has only basic widgets, and its README lists refactoring and translations as open to-dos. The latest release, 1.1.0 from August 2024, ships separate Apple silicon and Intel installers, and the repository saw commits in July 2026. The README does not state a minimum macOS version.
