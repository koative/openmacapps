Pulsar picks up the Atom editor after GitHub sunset it in 2022. You open a single file, a project folder or several projects in one window, then split the editor into panes to work on files side by side.

- A built-in package manager finds and installs packages, and you can publish your own.
- Language servers add autocompletion and code navigation.
- Multiple cursors, snippets and semantic selection speed up editing.
- Git integration switches branches, stages changes, resolves merge conflicts and can show open GitHub pull requests.

Pulsar runs on Electron. Its appearance and behaviour change through JavaScript and CSS in your own configuration files, and nearly every part can be adjusted that way. The default setup is usable without any of it.

Releases include separate disk images and ZIPs for Apple silicon and Intel Macs, named Silicon and Intel, next to Windows and Linux builds. The current version, 1.133.1, came out in November 2026.

If you are weighing it against Sublime Text or Visual Studio Code, Pulsar's difference is where it comes from: it carries on Atom's hackable package model, and its community maintains it under the MIT license.
