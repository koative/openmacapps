Swifty Download Manager is a download manager for macOS, iOS and iPadOS. It resumes direct HTTP and HTTPS downloads after a pause or restart, can use several connections for one file, keeps a history of finished and failed transfers, and can take over links sent from Safari or from a Chrome extension. It suits people who fetch large files regularly and want more control than the browser's downloader gives them.

The macOS app needs macOS 14 or later and is a universal build. The zip on the Releases page is signed and notarized. Browser-session downloads only work while the app is running, and POST downloads and custom authorization headers are not supported. The project publishes no account, advertising or telemetry, according to its README. The code is under FSL-1.1-MIT, which is not an open-source license until each version reaches its MIT date, so the project is listed as source-available.
