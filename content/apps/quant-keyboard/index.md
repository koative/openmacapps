Quant Keyboard corrects text typed in the wrong keyboard layout. When it recognizes a word typed in the other language, it erases the word, retypes it in the right layout and switches the input source. A hotkey converts a selected passage, and optional fixes handle common typing slips. It scores words with a local character model instead of block lists, and it sends nothing over the network. It suits people who write in two layouts and want the correction to happen as they type.

It requires macOS 13 or later on an Apple silicon Mac, since the release binary is arm64 only. The DMG is not notarized, so the first launch has to be allowed in System Settings. It needs Accessibility permission because it intercepts keystrokes. The app has no Dock icon. The MIT license does not cover the Quant name, logo or visual identity.
