DevSwitcher2 changes two shortcuts. Command-` cycles through windows of the current app, and an optional inter-app switcher takes over Command-Tab. Window titles can be trimmed by strategy, so Xcode projects and VS Code workspaces show their project name, and you can set per-app rules and custom hotkeys. It suits developers who keep many windows of the same app open at once. Its interface is available in English and Simplified Chinese.

It requires macOS 12.0 or later and Accessibility permission, which the app requests on first launch. The inter-app switcher is off by default and must be enabled in Preferences. The README does not say whether the build is notarized.
