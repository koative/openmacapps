CoWork OS is a desktop AI app that works on your files, documents, browser, inbox and scheduled jobs. It shows each file read, command and edit as it happens. With the default Ask for approval profile, the agent works freely inside your workspace but waits for your answer before anything leaves it, such as sending a message, using the network or credentials, or exporting files. It suits people who want an agent they can watch and control, with memory, workspace and history kept on their own machine. Model providers may charge for the usage you run.

The README lists Apple silicon and macOS 13 or later for the install script and the DMG, and says Intel Macs can use the npm install with Node.js 24. The DMG is not notarized, so on first launch you must choose Open Anyway under System Settings > Privacy & Security. The README says the curl install script avoids that prompt.
