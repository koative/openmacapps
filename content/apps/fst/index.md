Fst opens a single text file, highlights its syntax, and lets you edit and save it. Beyond themes, its README promises little more than that.

- Font size changes from the View menu or with Command-Plus, Command-Minus and Command-0.
- Settings and the View menu toggle line wrapping and line numbers, and Settings also holds the line height.
- Save As takes any file name without adding an extension, and documents save only when you ask.
- Make Fst the Default Editor sets it as the default app for code files, and since version 0.2 it also covers .ts files, which macOS otherwise treats as video.

Fst needs macOS 14 or later. Version 0.2, released in October 2026, is a Universal app for Apple silicon and Intel, signed with a Developer ID and notarized. You can download the ZIP from GitHub or install it with Homebrew from the developer's tap.
