Fst is a text editor for opening and editing single files. Its README describes it as a fast, minimal editor with syntax highlighting and themes, and little else. It suits quick edits to a config file, a script or a note, where a full code editor would be more than you need.

It needs macOS 14 or later and runs on Apple silicon and Intel. The app is notarized by Apple, so it opens without a Gatekeeper warning. The latest release is v0.2, published in October 2026.
