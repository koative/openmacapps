Friction is a motion graphics tool for vector and raster animation. Shapes and text are animated on timelines, with graph views for adjusting motion, path and text effects, experimental shader effects, and expressions written in JavaScript to drive parameters and effects. Several scenes, viewers and timelines can be open at once.

Finished work renders to video through FFmpeg or exports as animated SVG for the web. It grew out of the enve project and runs on macOS, Windows and Linux; the Mac build is universal and needs macOS 11 or later. The current release is a 1.0 release candidate, and the project notes that its binaries are not signed, so macOS may require extra steps before the first launch.
