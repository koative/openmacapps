Vasa is a canvas for people who organise research by spreading it out. You place text, sticky notes, images, links, audio, video, YouTube embeds and freehand ink on a pannable, zoomable board, and cards snap to each other with alignment guides. Each project is a single file, and the library lives in a Vasa Library folder under Documents. It suits people who otherwise collect this kind of material across browser tabs, folders and sticky-note apps.

It requires macOS 14 or later on Apple silicon; the release notes say Apple silicon only. The README does not mention notarization, so do not assume the DMG is notarized. Caveats: the README lists some AI provider workflows as still being wired up. AI features are opt-in and use a provider key that you set in Settings.
