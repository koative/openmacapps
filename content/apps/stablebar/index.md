StableBar replaces the macOS menu bar with a bar you arrange from widgets: the active app, a clock, battery, workspaces and more. Any script that prints text or JSON can become a widget, and popups show graphs, lists and controls. You can edit the bar in place or through a JSON file, with undo. A package store lists the commands, hosts and permissions a widget needs before it runs. Workspaces can follow AeroSpace, yabai or OmniWM, or use the macOS Spaces source without a window manager. It suits people who want a SketchyBar-style setup in a native app.

It requires macOS 14 or later on Apple silicon. The README says releases update themselves and points to a getting-started guide for permissions and beta updates. It does not say whether the build is notarized. The project is free and open source under the MIT license.
