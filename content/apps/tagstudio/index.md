TagStudio turns any folder into a library and lets you describe its files with tags that have aliases, colours and parent tags, plus text and date fields. Searches combine tags, paths, file types and media types with AND, OR and NOT, and a preview panel shows images, including RAW formats, as well as video, audio, text and several creative-app project files.

It is a tagging and cataloguing tool rather than a photo editor: files stay where they are, and the library data lives in a SQLite database inside a hidden folder at the library root. The project still labels its releases alpha. Builds for Apple silicon and Intel Macs are on GitHub releases; video thumbnails and playback need FFmpeg installed separately.
