Dopamine keeps a Mac awake from the menu bar, either indefinitely or for a set time, and can stop when the battery falls below a threshold you choose. Its main difference from older keep-awake tools is an option to switch off the closed-lid display backlight while the Mac keeps working, which lets long builds, renders or downloads run with the lid shut. The project positions it as a successor to Amphetamine and Caffeine. The project's 0.0-nit figure is its own claim.

The download is labeled for Apple silicon and the project lists macOS 12 through 15. The DMG is signed with a Developer ID and notarized, and the project says it has no telemetry without consent. A PKG installer is also published.
