Rectangle moves and resizes the frontmost window when you press a keyboard shortcut or drag the window to a screen edge. Each shortcut sends the window to a fixed position, such as the left half, a corner quarter, a third or the full screen.

Dragging works through snap areas. Pull a window to the left or right edge for a half, to the top to maximise, into a corner for a quarter, or along the bottom edge for thirds. An outline previews the target before you let go.

- Tile in Rows and Tile in Columns arrange the ordinary windows in the current Space on the focused window's display into a grid, and repeated presses cycle through layouts.
- Cycle stacked windows brings forward each window snapped to the same area in turn.
- Mouse side buttons can act as shortcuts in place of keys.
- Ignored apps release Rectangle's shortcuts while they are frontmost, so their own shortcuts keep working.

The current release requires macOS 14 or later. Older versions for macOS 10.15 to 13 and for 10.13 to 10.14 stay on the releases page. Downloads come as a DMG, a ZIP or a PKG, each holding a Universal binary for Apple silicon and Intel. It carries a Developer ID signature and Apple's notarization. Moving windows requires the Accessibility permission in System Settings.

Magnet also snaps windows into halves, thirds and quarters by shortcut or edge drag, but it is sold on the Mac App Store. Rectangle is free under the MIT license. Rectangle Pro is a separate paid upgrade, and the Multitouch app now includes all of it.
