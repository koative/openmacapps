IINA puts mpv, the open-source playback engine, behind an interface that follows Mac conventions, so you play video and audio in a familiar window.

You control it with trackpad gestures and the system media controls, and it supports Picture in Picture and Live Text. The on-screen controls, sidebars and other interface items can be rearranged. Community plugins add more. Examples include extra subtitle sources, video tools and alternative interfaces.

PotPlayer also plays video files, but its official site offers it only for Windows.

IINA runs on macOS 12 or later on Apple silicon and macOS 11 or later on Intel Macs. Each release ships as a single disk image, attached to the GitHub release and linked from the website. It is free, maintained by its community and supported by donations. The code is GPL-3.0, while the website artwork used for the icon and screenshot is credited separately.

The website states that IINA contains no tracking or telemetry.
