IINA plays video and audio through mpv, the open-source playback engine, in a window that follows Mac conventions. The formats come from mpv and the controls from macOS.

It works with trackpad gestures, the system media controls, Picture in Picture, and Live Text for copying words out of a paused frame. The on-screen controls, sidebars and other interface items can be rearranged. Plugins written by the community add more, such as extra subtitle sources, video tools or alternative interfaces.

PotPlayer, a player with wide format support and detailed playback settings, has no macOS version. IINA covers the same everyday job of playing almost any local file with subtitles, through a Mac interface instead of a Windows one.

The project's website lists macOS 12 or later on Apple silicon and macOS 11 or later on Intel Macs. Each release ships as a single disk image on GitHub and the website. The website states that IINA contains no tracking or telemetry.

IINA is free, maintained by its community and supported by donations. The code is GPL-3.0; the website artwork used for the icon and screenshot is credited separately.
