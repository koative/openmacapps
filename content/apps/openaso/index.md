OpenASO is a native macOS app for App Store optimisation research. You add apps and keywords, record ranking snapshots across storefronts, see which competing apps rank for each keyword, and follow ratings and reviews over time. Keyword and rating data can be exported as CSV, and the app ships MCP tools so an AI agent can run keyword research and metadata checks. It suits app developers and ASO specialists.

The DMG is a universal build for Apple silicon and Intel that requires macOS 15.0 or later, and it is notarized by Apple. Apple Ads and App Store Connect credentials are optional and only needed for account-backed features. Anonymous usage analytics are on by default and can be turned off in Settings. Data is stored locally with SwiftData.
