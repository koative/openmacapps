Nimble Commander shows two file panels side by side, and you copy or move items from one to the other without touching the mouse. More than a hundred actions have keyboard shortcuts, following the dual-panel file managers of the 1980s and 1990s.

- Search finds files by attributes or content, or through Spotlight, and the results can fill a panel for you to work on.
- The viewer shows text or hex and loads only part of a large file, so multi-gigabyte files open.
- Batch rename builds names from patterns, dates, counters and search and replace.
- A built-in terminal follows the panel as you navigate, and typing cd moves the panel.
- Archives open like folders, and FTP, SFTP and WebDAV servers work like local disks.
- Admin mode gives you root access inside the same panels once you enter administrator credentials.

You can change colors, fonts, hotkeys and most of the layout. A Classic presentation brings back a monospaced, text-mode look.

Version 1.9.0 needs macOS 12 or later. It is a universal app, signed with a Developer ID and notarized. The README marks Nimble Commander as no longer actively maintained, so later macOS changes may go unfixed. A Mac App Store edition also exists, and the website compares the two editions feature by feature.
