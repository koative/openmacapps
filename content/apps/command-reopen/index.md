Command Reopen is a menu bar utility for macOS. When you Cmd+Tab to an app that has no visible windows, it asks the app to reopen, which brings back a minimized window from the Dock or opens a new one. It needs neither Accessibility nor Screen Recording permission. It suits people who minimize or close windows and then lose track of them while switching apps.

The GitHub zip is the free direct build. It is signed with a Developer ID, notarized, and its bundle declares macOS 13 or later. The Mac App Store version is a separate build with a seven-day trial and paid unlock, and it sends anonymous analytics; the README says the GitHub build sends none.
