bindPDF combines several PDF files into a single document. The README covers installation and a short demo video, and nothing beyond merging. It suits occasional joining of PDFs without a full PDF editor.

The DMG is an Intel (x86_64) build with a minimum of macOS 10.14 according to its Info.plist, so Apple silicon Macs run it through Rosetta 2. It is not notarized and Gatekeeper rejects it, so the first launch has to be allowed in System Settings. The last commit is from October 2019.
