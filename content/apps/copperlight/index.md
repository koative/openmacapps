Copperlight is a launcher opened with ⌥ Space. One field opens apps and files, does math, currency and unit conversions, keeps a searchable clipboard history, moves windows, runs your own commands and snippets, and shows the next meeting and running timers. Settings live in a plain-text file you can keep in git. It suits people who want a keyboard launcher with more built-in tools and no account.

It requires macOS 15 or later, on Apple silicon or Intel. The release is signed with a self-signed certificate and is not notarized, so the first launch needs Open Anyway in System Settings, once. Some features need permissions or contact outside services: stock prices come from Yahoo Finance, and translation needs macOS 26. The README says the app has no telemetry and no account. It is GPL-3.0 licensed, so modified versions you distribute must remain GPL-3.0.
