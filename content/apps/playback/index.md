Playback is a video player built with Electron and Node.js. It plays MP4 and WebM files and can stream them to Chromecast. It can also open HTTP links, torrent magnet links and IPFS links, with WebTorrent support for peer-to-peer playback. It suits people who want a basic player for these sources.

The README lists OS X and Windows as supported platforms and gives no macOS version or chip requirements. The latest release, 1.6.0, is from December 2015. The Mac build is a zipped app on the releases page.
