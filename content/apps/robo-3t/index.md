Robo 3T, formerly Robomongo, is a MongoDB desktop client built around the mongo shell. You run shell commands in tabs and browse databases, collections and documents in the same window. Studio 3T acquired the project in 2017, and the README now says it is no longer being developed.

The README lists macOS 10.14 (Mojave), 10.15 (Catalina) and 11 (Big Sur) as supported, and the last release's Mac file is an Intel x86_64 build. It points to Studio 3T Community Edition as the successor. The project's site describes that edition as free for non-commercial personal use only, so it is not a free replacement for work use.
