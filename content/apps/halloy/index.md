Halloy is an IRC client for macOS, Windows and Linux. Channels, private messages and server buffers open in panes you can split and rearrange in one window, and it keeps up with modern IRC through a long list of IRCv3 capabilities such as chat history, message replies, reactions, typing notices and SASL login.

Servers, themes, highlights, notifications and keyboard shortcuts are set in a configuration file documented on the project site. It can connect through the soju and ZNC bouncers, and supports file transfers, logs and custom themes.
