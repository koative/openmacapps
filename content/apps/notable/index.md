Notable is a small note-taking app that keeps your notes on your own computer. It searches tags, tag prefixes and full text as you type, opens several notes in tabs, autosaves each note, and can encrypt individual notes. It suits people who want a simple, keyboard-friendly notebook rather than a large knowledge base.

The release zip contains an executable and a macOS app bundle. The download is an Intel (amd64) build, so on Apple silicon Macs it runs through Rosetta 2. The README does not state a minimum macOS version. Syncing notes through Syncthing is marked experimental. The latest release, v0.4.0, is from April 2023, and commits since 2024 are mostly dependency updates.
