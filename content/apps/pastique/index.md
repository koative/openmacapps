Pastique keeps a clipboard history of text, images and files, and opens a picker on Cmd+Shift+V. Copied items are sorted into categories such as colors, links, commands and personal information, so they are easy to find at a glance. You can start typing straight away to search, including with Chinese, Japanese and Korean input. The README says items from password managers are skipped, and the last 500 items are kept. It suits people who copy a lot of mixed content and want a simple history without extra steps.

The README does not state a minimum macOS version or chip support, so check the release notes before installing. The build is not notarized: on first launch macOS shows "Apple could not verify Pastique", and you allow it once per install under System Settings > Privacy & Security > Open Anyway. The README says later versions then update silently. Support through a donation link is optional.
