Impulso is a SwiftUI task manager for the Mac. Each task is scored on impact, fun, momentum, alignment and effort, and the score sets its priority. Tasks sit in Active, Completed or Backlog views, can be reordered by dragging, and can be found through a command palette. Automatic backups and JSON import and export are included. It suits people who want a single-app task list that ranks what to do next.

It needs macOS 14.5 or later. The README does not say whether the build is notarized, so macOS may ask you to allow the first launch in System Settings. The project is unmaintained: its last release is from November 2024.
