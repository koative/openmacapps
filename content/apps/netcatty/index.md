Netcatty is a connection manager for people who work on many remote machines. Hosts and groups live in a searchable vault with grid, list and tree views, and sessions open in tabs or split panes. Besides SSH, with key management and port forwarding, it handles Telnet, Mosh, serial ports and local shells, and a monitoring view shows CPU, memory, disk and network readings for connected hosts.

File work happens in a dual-pane SFTP browser with drag-and-drop transfers and a built-in editor for quick changes, so it can stand in for a separate SFTP client on SSH servers. It also ships an AI assistant that can inspect hosts and run commands through chat. Releases come often, with separate macOS builds for Intel and Apple Silicon on GitHub.
