CropBatch edits a folder of images with one set of choices. You set a crop once, then add blur regions, rounded corners, a grid split or a text or image watermark, and export every file with the same resize, format and naming rules. Export covers PNG, JPEG, HEIC, TIFF and WebP. It suits people who prepare screenshots or photos for publishing and want consistent output without editing each file by hand.

It needs macOS 15 or later and is a universal build. The disk image is signed with a Developer ID but is not notarized, so the first launch has to be allowed in System Settings. Image processing stays on the Mac, but update checks contact the update service. The repository's README describes version 1.7 as in final testing; this entry covers the public 1.6 download.
