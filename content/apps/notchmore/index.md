NotchMore turns the area around the notch into a control surface and adds several small Mac tools in one app: clipboard history for text, images and files, media controls, a file shelf, a window switcher, Dock previews, paste without formatting and Finder cut-and-paste. Each feature can be switched on or off. It suits people who would otherwise run several small utilities for these jobs.

NotchMore needs macOS 15.4 or later. The 1.3.0 zip is a universal build signed with a Developer ID and notarized by Apple. It asks for permissions only when an enabled feature needs them: Accessibility and Input Monitoring for input features, Screen Recording for window and Dock previews, and Camera for the mirror.
