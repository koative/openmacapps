Messenger is a small Mac app that loads Facebook's standalone Messenger site in its own window, so you do not need a browser tab for it. The README calls it an unofficial hobby project and says it is not a Facebook product. It suits anyone who wants Messenger in a separate window on the Mac.

The app requires macOS 10.10 or later, and the build is Intel only (x86_64). It is signed with a Developer ID certificate but is not notarized, so the first launch must be allowed in System Settings. The latest release is from April 2017. The README links an older 0.1.4 build for users still on OS X 10.9.
