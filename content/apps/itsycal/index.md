Itsycal puts a small calendar in the menu bar. Click it, or press a shortcut you set, to see the month along with events from the calendars you tick in its settings, chosen from those set up in the Mac Calendar app.

You can create and delete events from Itsycal, but you cannot edit them. It also shows Reminders that have a due date, which you can tick off, and it can join virtual meetings.

- Keyboard controls cover navigation, with Vim motions and repeat counts, and a jump to any date.
- A URL scheme, `itsycal://date/`, opens the panel at a given day.
- The panel can show up to two months at once, with ISO week numbers and several font sizes.
- Itsycal can stand in for the system clock in the menu bar, and you can configure how it looks.

A setting makes it beep on the hour. Dark Mode is supported.

The current build requires macOS 27, and an older build for macOS 11 and later stays on the download page. The current build is an Apple silicon app, notarized. Its code is under the MIT license.

Fantastical connects to Google, Microsoft 365, Exchange and other services, keeps tasks next to events, and turns a typed sentence into an event. Itsycal reads the calendars the Mac Calendar app already holds and keeps to viewing, creating and deleting events. Its calendar button can even open Fantastical instead of Calendar, once you make Fantastical the default calendar app.
