Vicinae is a command palette you summon with a shortcut. It launches apps, searches files, keeps a clipboard history, expands text snippets, picks emoji, does quick calculations and switches between windows and browser tabs, all from one search field.

It can be extended with React and TypeScript extensions that are compatible with the Raycast extension API, and it can install them from both its own store and Raycast's. Raycast-style script commands work as well.

macOS support has been in beta since version 0.23; the project also targets Linux and Windows. The Mac build is a notarized disk image for Apple silicon only and needs macOS 14.4 or later.
