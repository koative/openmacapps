Achico compresses PDFs, images and videos. You drag files onto the window or pick them from a dialog, then choose a quality level, an optional maximum size for images and videos, and whether metadata is kept. It shows how much space each file saved. It suits people who want to shrink files before sending them without learning a separate tool for each format.

It requires macOS 14.0 or later and is a universal build. The app is signed with a Developer ID, notarized and stapled, so it opens without a first-launch workaround. The last release, 3.2.1, dates from November 2024.
