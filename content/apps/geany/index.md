Geany opens your source files in tabs, colors their syntax and lets you compile, build and run them from its Build menu. Errors from a build are listed, and Next error jumps to the line. It depends on little beyond GTK, so it stays small next to a full IDE.

While you type, it helps with the usual things:

- completion of symbols, of common constructs such as if, for and while, and of XML and HTML tags
- call tips and code folding
- a symbol list for jumping around the current file
- support for more than 50 languages, from C, Java and PHP to Python and Perl, plus config files, diffs and SQL

Plugins add version control for Git and Subversion, a spell checker and a project organizer. You can also install color themes and define new file types.

On the Mac, Geany 2.1 comes as two disk images, one for Apple silicon and one for Intel. The Apple silicon image is signed with a Developer ID and notarized. Its windows are GTK windows, and the interface is translated into over 40 languages.

UltraEdit and Sublime Text, two other programmer's editors, are sold under paid licenses. Geany is free software under the GPL, version 2 or later.
