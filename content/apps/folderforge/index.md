FolderForge replaces Finder folder icons with your own designs: colours and gradients on each layer of the folder shape, image fills, SF Symbols, emoji, text or another app's icon as an overlay, or a full ICNS file. Designs can be saved as styles and applied from a Finder Services menu, and the original icon is kept so it can be restored.

Smart Style rules match folders by name, path, marker files or file types and preview every change before styling a whole workspace, and a command-line mode in the app binary does the same from scripts. It is a SwiftUI app for macOS 14 or later, offered as a notarized download on GitHub and free on the Mac App Store.
