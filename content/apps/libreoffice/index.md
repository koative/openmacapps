You write documents, build spreadsheets and prepare slide decks in LibreOffice's six modules. Writer handles text, Calc spreadsheets and Impress presentations. Draw covers diagrams and illustrations, Base databases, and Math formulas.

Files load and save in the OpenDocument format by default (.odt, .ods, .odp). LibreOffice also opens Microsoft Office files such as .docx, .xlsx and .pptx, and it can save in Microsoft formats. Microsoft Office covers the same ground of word processing, spreadsheets and presentations. The difference is the default format: LibreOffice starts from OpenDocument.

It runs on macOS 11 or newer with an Intel or Apple silicon processor. There is no universal app. Apple silicon and Intel each get their own disk image.

The Document Foundation and contributors make LibreOffice, which is free to download and use. Its source code is under the Mozilla Public License 2.0.

A few optional features rely on Java. On a Mac they need a full JDK, not just a JRE.
