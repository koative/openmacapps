Cove brings Claude Code and Codex into a native Mac window. A sidebar lists projects and sessions that you can search, pin, rename, archive and resume. The composer handles multiline editing, attachments and pasted images, and an inspector shows tasks, changed files and diffs, with line comments you can send back to the agent. Git status, commit, pull, push and pull request checks run through your installed gh command. Cove runs the CLI you already have, under your own account and settings. It suits people who use Claude Code or Codex from Terminal and want sessions and diffs in one window.

Requires macOS 14 or later on Apple Silicon, with Claude Code or Codex installed and signed in. This is a preview: the DMG is ad-hoc signed and has not been notarized by Apple, so the first launch needs Open Anyway in System Settings under Privacy & Security. The interface is primarily Chinese, automatic updates are not included yet, and the README lists known limitations, such as new Codex conversations that can disappear after closing on one tested CLI version. Usage figures depend on the CLI and are estimates.
