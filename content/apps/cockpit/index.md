Cockpit is a daily dashboard that combines calendar events, music, Notion pages and mail in one view. A macOS menu-bar helper owns the data sources and the rules that choose which page to show, based on the front app, the calendar and Focus. The README also describes iPad and iPhone companions with widgets and Live Activities. It is for people who want their day on one screen instead of across several apps.

The release zip contains the macOS app, which needs macOS 14 or later. It is ad-hoc signed and not notarized, so allow it on first launch in System Settings. The app asks for automation permission per app the first time it reads Spotify, Music, Safari, Chrome, Terminal or System Events. The iPad and iPhone companions are not in the zip; the README says they are built from source in Xcode.
