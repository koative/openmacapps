================================================================================
NanoVSR — production reconstruction architecture
================================================================================

NanoVSR architecture adaptation
Source: https://github.com/filippawlicki/nanovsr
Lucid's production network adapts the RepVGG blocks and bilinear residual to
single-frame, pixel-unshuffled, 2x reconstruction without BatchNorm. All shipped
weights were trained by this project; no pretrained NanoVSR weights are used.

================================================================================
SPAN — historical models and development tools
================================================================================

Source: https://github.com/hongyuanyu/SPAN
License: Apache License, Version 2.0.
The development code adapts the SPAN architecture for pixel-unshuffled codec
restoration. Earlier releases used locally trained SPAN weights. Lucid 1.0.0
ships the Nano-derived model described above. The SPAN license and attribution
are retained in Lucid/Resources/ThirdPartyNotices.txt and Tools/architectures.


================================================================================
Algorithms implemented from published descriptions
================================================================================

The filters in Lucid/Metal/DetailEnhancer.swift are written here from the
published descriptions of the following work. No code was copied from these
projects, and they are named because the ideas are theirs:

  * CDEF, the constrained directional enhancement filter, from AV1
    — Steinar Midtskogen and Jean-Marc Valin. The per-direction divisor table
      matches the one used by dav1d.
  * Temporal accumulation with neighbourhood clipping
    — Brian Karis (temporal anti-aliasing) and Playdead's shipped implementation.
  * Stochastic debanding
    — the approach used by libplacebo and mpv.
  * Contrast-adaptive sharpening
    — the lobe from AMD FidelityFX CAS.
  * Oklab
    — Bjorn Ottosson.
  * The deblocking filter
    — ITU-T Recommendation H.264, Tables 8-16 and 8-17, run without a bitstream.
