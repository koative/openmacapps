Tidymint scans for caches, logs, old installers, large files, duplicates and the leftovers of removed apps, explains what each group is, and marks it as safe, to review or locked, so risky items are never selected for you. Every clean moves files to the Trash, and the Trash page can put the last run back. Before removing duplicates it can check the project folders you name for scripts that still reference a file.

It also maps disk usage as bubbles, removes apps together with their support files, and has per-app pages for chat apps and browsers. The app runs on macOS 14 or later on Apple silicon and Intel, in English and Vietnamese. The project started in October 2026, and its builds are not notarized, so the first launch has to be allowed in System Settings.
