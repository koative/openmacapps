SakuraWallpaper sets an MP4, MOV, M4V or animated GIF as a live desktop background, or a PNG, JPEG, HEIC, WebP, BMP or TIFF image. Each display can keep its own folder, playlist, interval and shuffle setting, and displays can be linked so that their rotations change together. It has a Recent list, a menu bar status item, launch at login, and a battery saver that pauses playback at 20 percent or below when the Mac is not charging. The interface is in English and Chinese. It suits people who want a small wallpaper utility rather than a desktop-effects suite.

Requires macOS 12.0 or later. Image wallpapers are applied as the system desktop picture; for video, the current frame is written to the system desktop picture when the wallpaper changes and when the screen locks. The README describes the project as feature-complete, with future work limited to fixes and compatibility. It documents an `xattr` command for the "damaged" message and makes no notarization claim.
