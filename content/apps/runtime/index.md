Runtime is a desktop agent that drives Chromium browsers such as Chrome and Edge. Instead of letting a model work out each click, it runs predefined "skills": step-by-step recipes for sites such as Amazon, Gmail, Google and Notion. The actions run in your own logged-in browser session, so you do not need a separate profile. It suits people who want an assistant to repeat common web tasks, such as triaging email or gathering sources for research.

The app is universal (Apple silicon and Intel), notarized by Apple, and its bundle declares macOS 10.13 or later. The README's setup uses a Gemini API key. Recipes are hand-written and cover only the sites the project has added so far. The latest release is from August 2025.
