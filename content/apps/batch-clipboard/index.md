Batch Clipboard does one clipboard job. You copy several items from a source document with Control-Command-C, then paste them one at a time, in the same order, into a target document with Control-Command-V. It is a menu bar utility rather than a full clipboard history, and it can also start a batch from the Dock icon. It suits anyone who regularly moves several snippets, such as rows or references, between documents.

Batch Clipboard supports macOS 10.15 Catalina or later according to its Info.plist, but the README says it runs best on the latest macOS and that testing on older systems was limited. The 2.3 release is a universal build signed with a Developer ID and notarized. The GitHub edition is free and notifies you of updates. The Mac App Store edition is the same app with an optional in-app purchase. The interface is English only.
