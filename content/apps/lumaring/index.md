LumaRing is a small ring-shaped switcher for moving between apps, individual windows and browser tabs, and for running app shortcuts. It is written natively in Swift, and the README describes the download as about 2.9 MB. Releases are published on GitHub, and the README also lists a Homebrew cask from a third-party tap.

It requires macOS 14 or later and ships builds for both Apple silicon and Intel. The app is not notarized: it is signed with a local certificate, so macOS blocks the first launch until you allow it under System Settings > Privacy & Security.
