Revu is a study app for macOS that schedules reviews with the FSRS algorithm. You organise cards into decks, folders, exams and study guides, import Anki packages, CSV, Markdown or JSON, and keep the data in a local SQLite database with no account. The README calls this the standalone open-source edition; the commercial product at revu.cards adds sync and AI features.

The README says macOS 14 or later, but the app bundle in the release DMG declares a minimum of macOS 26.0, so check before installing. The build is universal (Apple silicon and Intel) and is not signed or notarized, so the first launch needs the right-click Open step described in the README. The name and logo are trademarks that the GPL does not license.
