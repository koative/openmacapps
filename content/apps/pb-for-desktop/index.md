PB for Desktop is an unofficial desktop client for Pushbullet. It shows your Pushbullet notifications as native notifications, with a filter to choose which ones appear and a choice of sounds. It suits people who use Pushbullet and want those notifications on their computer. The project states that it is not affiliated with Pushbullet, Inc.

The README lists macOS Mojave 10.14.6 as the tested version. SMS sending and inline SMS replies are marked as beta features. The README's to-do list still includes signed binaries for distribution, so do not assume the build is signed. The last commit is from August 2020.
