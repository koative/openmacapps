RClick adds entries to the menu you get when you right-click in Finder. Select a file or folder, open the menu and pick one of the extra actions.

- New files from templates: plain text, JSON, Markdown, Word, PowerPoint and Excel, plus Pages, Keynote and Numbers.
- Copy the full path or only the file name.
- Open the selection in any installed app, with custom arguments and environment variables. Presets cover common editors, terminals and IDEs, and terminals receive the containing folder.
- Delete without the Trash, after a confirmation that holding Option skips.
- Show or hide a file, or send it with AirDrop.
- Pin folders you use often to the menu.

The menu comes from a Finder Sync extension, paired with a menu bar app that holds the settings. After the first launch you may need to switch the extension on under System Settings, Privacy & Security, Extensions. File operations ask for access one folder at a time, and some automation features need the Accessibility permission. The interface follows the system language and comes in English, Simplified Chinese, Japanese, Spanish and French.

RClick requires macOS 15.6 or later. Release 2.3.3 comes as a DMG or ZIP, and the app in the DMG is built for Apple silicon only, signed with a Developer ID and notarized.
