zisla is a workspace that appears along the top edge of the screen when the pointer reaches the top centre, and gets out of the way when you are done. It keeps now-playing media, a clipboard history with quick actions, a handoff tray for files and links, timers, downloads and mail alerts in one place, and it shows the task state of local AI coding tools such as Codex and Claude Code. Other modules cover a PDF toolkit, a pomodoro timer, system statistics and voice transcription.

It runs on macOS 14 or later. The universal DMG covers Apple silicon and Intel, and the README names Apple silicon as the supported configuration. The release is signed with a self-made certificate, not a Developer ID, and it is not notarized, so the first launch needs Open Anyway in System Settings. Permissions are requested only when a module first needs them. Some features need extra tools: yt-dlp for downloads and LibreOffice for Office-to-PDF conversion.
