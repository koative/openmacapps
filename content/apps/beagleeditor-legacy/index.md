BeagleEditor Legacy is a desktop code editor written in Python. It highlights syntax for Python, C, C++, C#, CSS, HTML and JavaScript, offers autocomplete, can run a Python file, and loads plugins. The project's README says a newer editor, beagleeditor/editor, has replaced it, so this is the older line for people who already use it.

The README gives a Mac zip and DMG in the releases, or a Python install from source. It does not state a minimum macOS version or whether the Mac build is notarized, so check both before you launch it.
