AFFiNE puts written documents and a freeform whiteboard on the same canvas: any page can switch between a block editor and an edgeless view for sketches, diagrams and notes. Database blocks turn lists into tables and kanban boards, and pages link to each other to form a knowledge base. Workspaces are stored locally on the Mac and work offline; syncing and collaboration use AFFiNE Cloud or a self-hosted server.

The desktop client is AFFiNE's Community Edition. Most of the code is MIT-licensed, while the server and a shared native module carry an Enterprise Edition license that, by its own terms, places any part distributed in the Community Edition under MPL-2.0. The desktop app includes that native module, so it is covered by MIT and MPL-2.0, and the enterprise restrictions reach only parts that are not distributed in the Community Edition. Builds are available for Apple silicon and Intel Macs running macOS 11 or later.
