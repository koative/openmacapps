Re:notch uses the strip around the MacBook notch as a compact dashboard. It shows local servers and ports, Git status, Docker containers and build jobs, and it can show Apple Music or Spotify playback. A Pomodoro timer can block selected websites during a session. It suits developers who want project status at a glance.

The README asks for macOS 13 or later and says the app keeps its data on the Mac with no telemetry. It does not say whether the build is notarized, so the first launch may need to be allowed in System Settings. The browser extension is optional and is loaded by hand from the repository.
