TaskNxt lives in the menu bar as a popover. Each tab has three fixed lanes, Now, Nxt and Ltr, and you drag tasks between them to triage. Completed tasks are purged after a set period or moved to an optional archive. Up to four tabs, a global hotkey and a badge with the active tab's open-task count are included. It suits people who want a quick daily list without an account or a separate window.

It requires macOS 13 or later on Intel or Apple silicon; the release is a universal build. The app is ad-hoc signed and not notarized, so the first launch needs the right-click and Open step that the README describes. The project website describes an optional Google Tasks sync that the README does not mention.
