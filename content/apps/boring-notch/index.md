Boring Notch turns the MacBook notch into a panel that expands when you hover over it. It opens as a music control centre, with a live playback view and a visualizer, and the same space holds several smaller tools.

- Calendar and reminders.
- A file shelf where you drop files and send them with AirDrop.
- A mirror view.
- Battery charge and a charging indicator.
- Replacements for the system volume, brightness and keyboard backlight overlays.
- Gesture controls you can customize.

Boring Notch needs macOS 14 Sonoma or later and runs on Apple silicon and Intel Macs. The team has no Apple Developer account, so the app is not notarized and macOS warns about it on first launch. The README gives a Terminal command that clears the warning, and installing from the project's Homebrew tap avoids it. The latest stable download is version 2.7.3, and 2.8 is in release candidates.

Settings open from a star in the menu bar. They include sizing the notch area to fit different displays. The roadmap still lists Bluetooth device activity, weather, lock screen widgets and an extension system as unfinished.
