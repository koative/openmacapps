Condution is a task dashboard for checklists and project lists. You can put tasks in projects, tag them, set start and due times, filter and sort by those fields, and share workspaces that others can use without an account. It is built with Electron, and the README links to iOS and Android apps as well. It suits people who want a plain task list that they can share, rather than a full project-management suite.

The README says the app is free, with optional Patreon donations. To build from source you need a Firebase configuration file, and the README says the production build command is not yet written for v1.0. The badge says actively developed, but the last commit on the beta-v1.2.0 branch is from September 2023. The README does not state macOS requirements or whether the builds are notarized.
