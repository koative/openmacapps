Touch Bar Preview displays an image you drop onto it on the Touch Bar of a MacBook Pro. The README gives the expected size as 2170 by 60 pixels, equivalent to 1085 by 30 points, and images of other sizes are stretched to fit. The app places the design over the system Esc button and Control Strip, so the design does not need to leave room for them, and the README explains why the right-hand system buttons cannot be hidden.

The README says the app requires macOS 10.12.2 or later, and the binary is built for Intel (x86_64) only. The download is signed with a Developer ID certificate but is not notarized by Apple, so the first launch may need to be allowed under System Settings > Privacy & Security. The project has had no release since October 2018, and its last commit is from July 2019.
