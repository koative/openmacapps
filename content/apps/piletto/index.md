Piletto is a color workspace for designers. You sample a pixel from the screen, and it lands in the palette you are working in, where you can name it and add notes. Codes can be copied as HEX, RGB, HSB, HSL, CMYK or LAB, and CMYK can use an ICC profile you choose. Palettes are saved as a JSON file in your Documents folder.

Requires macOS 14 or later. The DMG is ad-hoc signed and not notarized, which we checked on the release tagged Cluster (version 1.0.2), so the first launch needs right-click Open or approval in System Settings. Generating palettes from a word or mood uses an optional on-device MLX model that you select yourself. The interface is in English and Russian.
