mSPACES adds separators to the menu bar so you can split its icons into groups. Related items, such as sync tools on one side and system controls on the other, end up between two separators instead of one long row.

To add a separator, click an existing one and choose New Separator. To move it, hold Command and drag it along the menu bar, the same way macOS lets you rearrange other menu bar items.

Each separator has its own style. It can be a plain space, a tab, a dot, a bar or a dash, so you can use wider gaps for big groups and a thin mark for small ones.

The app does one thing and stays out of the way. It does not hide icons or move them behind a menu, which is what dedicated menu bar managers do. Updates come from GitHub releases.

The interface is in English, French, Spanish and Italian, following the system language. Releases are arm64 builds for macOS 13 or later, signed with a Developer ID and notarized. The code is MIT-licensed.
