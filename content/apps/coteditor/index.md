CotEditor opens any plain-text file, from a quick note to a config file or a Python script, in an ordinary Mac document window. It starts fast enough for a one-line fix.

- Syntax highlighting for more than 60 languages, such as HTML, PHP, Python, Ruby and Markdown, plus definitions you write yourself.
- Find and replace with regular expressions, using the ICU engine.
- An outline menu that jumps to sections the syntax marks out.
- A split editor that shows different parts of one document side by side.
- A character inspector that shows the Unicode data of a selected character.
- Scripts in Python, Ruby, Perl, PHP, shell, AppleScript or JavaScript that act as your own macros.

Encodings get particular care. CotEditor detects a file's encoding and can list the characters that would be lost when you convert to another one. For Chinese, Japanese and Korean text it offers vertical layout. Documents are backed up automatically while you type, and every setting, syntax definitions and themes included, sits in a normal settings window.

Notepad++ fills a similar role for quick text and code edits, but it runs only on Windows. CotEditor is written for macOS alone and keeps its options few on purpose.

CotEditor supports the two latest major versions of macOS, so 7.1.3 needs macOS 26. Older versions for earlier systems are in the archives on coteditor.com. The GitHub DMG holds a Universal app, Developer ID-signed and notarized. The same app is also free on the Mac App Store.
