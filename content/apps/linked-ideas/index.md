Linked Ideas is a macOS app for writing ideas as concepts on a free-form canvas and connecting them with links, instead of arranging them in a tree. Concepts can be formatted, coloured and aligned, links can carry text, and documents can be stored in iCloud. An iOS app in the same project opens the documents for reading.

The app bundle declares macOS 10.11 or later and is an Intel (x86_64) build. The zip is signed with a Developer ID certificate but not notarized, so the first launch must be allowed in System Settings. The project has had no release since September 2017.
