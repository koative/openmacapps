Blockbench builds low-poly 3D models with pixel-art textures and animates them, in one editor. You can work from cuboids for a Minecraft look or shape freer meshes with the mesh tools.

- Textures are painted directly on the model in 3D, in a 2D editor or in an outside image editor you connect.
- Blockbench can generate a UV map and a texture template so you can start painting right away.
- The animation editor rigs a model and keys position, rotation and scale, with a graph editor for fine-tuning the motion.
- A built-in plugin store adds tools, export formats and model generators.

The code is GPL-3.0, with an exception: plugins and themes that use the Blockbench API may be proprietary or paid. Models, textures and animations you make belong to you.

Mac releases come as separate disk images and ZIPs for Apple silicon and Intel. The 5.2.2 Apple silicon app needs macOS 12 or later and is Developer ID-signed and notarized.

Finished models export to standard formats for rendering, 3D printing or game engines, and dedicated formats cover Minecraft Java and Bedrock Edition. The same editor also runs as a web app in the browser.
