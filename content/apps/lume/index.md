Lume is a native player for Apple platforms that connects to an Xtream Codes account or imports M3U and M3U8 playlists that you supply. It indexes the catalog locally for browsing and offers live TV with a program guide, catch-up where the provider supports it, a Multi-View grid of up to four channels, and watch progress with optional Trakt, Simkl and MDBList sync. Playback can use VLCKit, KSPlayer, AVPlayer, Lume's own beta engine or the optional AetherEngine. The project says it ships with no channels or content of its own.

It suits people who already have an IPTV subscription and want a native Mac interface for it. The macOS sideload build is listed on the project's site as free and fully unlocked; the App Store edition offers the same code with paid Lume Pro features such as the recording server, Chromecast casting and Multi-View.

The Mac build needs macOS 15 or later. The sideload zip is ad-hoc signed and not notarized, so macOS blocks the first launch until you allow it in System Settings, Privacy & Security. The code is AGPL-3.0, and the README points to an anti-piracy policy: use it only with streams and providers you are entitled to use.
