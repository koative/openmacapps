PsychoPy is a long-established package for creating experiments in the behavioural sciences, used both in research labs and for teaching. Its Builder lets you lay out an experiment as routines of stimuli and responses on a timeline without writing code, while the Coder view and the underlying Python library give full control when you need it.

It is designed for precise timing of visual and auditory stimuli and keyboard or device responses, and Builder experiments can also be exported to JavaScript and run online in a web browser through Pavlovia.

For macOS the project offers PsychoPy Standalone, the stable Python app, with Apple silicon and Intel builds, and PsychoPy Studio, a rebuilt Electron interface that is still in beta. The Standalone app and library are under GPL-3.0; the Studio interface code is under MIT.
