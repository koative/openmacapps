Hydrogen sequences drums from patterns. In the Pattern Editor you place hits for each instrument of a kit on a grid, and the Song Editor lines those patterns up along a timeline that can also carry tempo changes.

- Each note has its own properties, such as velocity, pan and a lead or lag in timing, and a piano-roll view is also available.
- Swing and humanize controls loosen the feel of a song.
- Instruments can stack several sample layers, and the Sample Editor can pitch-shift and time-stretch samples when Rubber Band support is available.
- A mixer gives each instrument its own channel strip.
- MIDI input and output and an OSC interface let a controller or other software drive it.

Version 1.2.7 is a patch release with bug fixes and updated translations. It opens songs and kits made with the old 0.9.3 version and prepares the file formats for the coming 2.0.

The Mac download is a disk image for macOS 10.14 or later. It holds an Intel-only build with no code signature. Builds for older systems are on the project's homepage, and the same release covers Windows and Linux. Hydrogen is licensed under GPL-2.0 or, at your choice, any later version.

Many drum kits are available, and the Sound Library keeps kits, patterns and songs in one place. Besides sequencing, Hydrogen plays its kits as a drum synth, and the project pitches it for anything from practice at home to live sets.
