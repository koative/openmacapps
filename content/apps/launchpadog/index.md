LaunchpadOG recreates the full-screen Launchpad grid of your installed apps, a view Apple replaced with a Spotlight-based list. It keeps the grid and folders, its search matches any part of an app name, and a small settings window opens with Command and comma. It is for people who miss the old layout and want a simple app launcher.

It requires macOS 26 or later. The release is a zip that is not notarized, so the first launch must be allowed in System Settings. The project lists Xcode 26 only for building from source. The most recent release is from November 2025, so expect slow updates.
