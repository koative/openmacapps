DockFlip adds Windows-style window handling to the macOS Dock: the Dock lists each app's windows, a Flip 3D Command-Tab switches between windows rather than apps, and window snapping works with a Snap Assist step. The real Dock stays in place and the features are added beside it. It suits people who juggle many windows and want Windows-like control, and it needs only one permission, Accessibility, with no screen recording.

It requires macOS 26 or later and runs on Apple silicon and Intel. The app is not notarized, so the first launch and every update need Open Anyway under System Settings, Privacy & Security. The README says it has no networking code, analytics, crash reporter or update check. A build from source is signed with a different identity from the release, so macOS asks for Accessibility again when you switch between them.
