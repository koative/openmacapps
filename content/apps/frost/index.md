Frost hides the menu bar icons you rarely use and brings them back with one click on its snowflake icon. Hidden items can close again after a delay or once you are done with them, and a layout editor lets you drag icons between sections. On notched Macs it can show the hidden icons in a Frost Bar panel instead. It suits anyone with a crowded menu bar who wants an alternative to Bartender.

It requires macOS 26 or macOS 27, on Apple silicon or Intel. The release is signed with a Developer ID and notarized. Frost needs Accessibility permission to identify and move icons; Screen Recording is optional and only adds real icon images. Its only network access is a daily Sparkle update check against GitHub Releases. The README says that on macOS 27 some behavior has been verified on one unnotched display only.
