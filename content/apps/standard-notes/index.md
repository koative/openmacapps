Standard Notes encrypts your notes on the Mac before they sync, and the company says only you can read them. You write in the desktop app, organize notes with tags, and pick them up on the web, Windows, Linux, iPhone or Android. Syncing needs a Standard Notes account, which you register for once and then sign in with on each device.

The free Standard plan includes:

- end-to-end encrypted sync on any number of devices
- plain text notes with tags, and offline access
- a password on individual notes
- full export, encrypted or as plain text
- two-factor sign-in and a daily encrypted backup sent by email

Paid plans unlock the Super note type for Markdown, rich text and checklists, plus spreadsheets, nested folders, an authenticator for your 2FA codes, a web clipper and longer revision history. The top plan adds encrypted file storage. The source code is public, and you can host your own sync server.

Release 3.202.11 has separate DMG and ZIP builds for Apple silicon and Intel, and the Apple silicon app needs macOS 11 or later.

Evernote gathers notes, scans and clipped web pages into notebooks. Google Keep is built for quick notes, lists and reminders. Standard Notes encrypts your notes and tags end to end, and its client code is AGPL-3.0, so you can read how it works.
