MinimalClock is a screen saver that fills the display with the current time and nothing else. You unzip the download, open the screen saver file and choose Install, then select MinimalClock as the screen saver in System Settings. It suits people who want a quiet clock on an idle screen rather than a configurable display.

The bundle contains only an Intel (x86_64) binary and its Info.plist sets the minimum at macOS 11.0, so on Apple silicon it runs through Rosetta 2. The release is ad-hoc signed and not notarized. The README says that if the screen saver does not run, it has to be allowed under Privacy & Security. The last commit is from January 2022.
