muCommander shows two folders side by side, and you copy, move or rename files from one pane to the other from the keyboard. Every shortcut can be reassigned, and each pane holds several tabs.

The same panes open far more than local disks. Through its virtual file system muCommander browses:

- FTP, SFTP, SMB, NFS and HTTP servers
- Amazon S3 buckets and Hadoop HDFS
- Dropbox and Google Drive accounts
- Bonjour services on the local network
- Archives opened like folders: ZIP, 7z, RAR, TAR, BZip2, GZip, ISO/NRG, AR/Deb and LST

Saved passwords go into a credentials manager, and bookmarks work across all of these locations. Batch rename handles a whole selection at once. Checksums can be calculated for selected files, and files can be emailed straight from the panes.

The app is written in Java and runs on macOS, Windows, Linux and any other system with Java support. Toolbars, themes and the interface language are configurable.

The macOS downloads are separate DMGs for Apple silicon and Intel. A third, architecture-neutral DMG is for macOS 10.15 Catalina and older.
