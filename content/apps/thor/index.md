Thor binds a global keyboard shortcut to each application you choose. Press the combination and that app opens. You add apps to a list in Thor's settings and give each one its shortcut, so the apps you use most each sit one key combination away.

You can reorder the list by dragging, hide Thor's icon from the menu bar, and export your shortcut settings as a JSON file. The README credits the MASShortcut library and says the interface idea came from Pomodoro One.

Version 1.5.16 from September 2024 is the latest release, and the repository has had no commits since then. That version requires macOS 12 or later. The GitHub release is a ZIP containing a Universal app for Apple silicon and Intel, Developer ID-signed and notarized. Thor is free under the MIT license, and the README also links to a Mac App Store listing.
