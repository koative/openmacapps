Mkchromecast streams the audio from your Mac to Google Cast devices and Sonos speakers, and it can also cast video files. It runs from the terminal, and a beta system tray menu provides controls. It suits people who want the music from their Mac playing on a speaker in another room.

The macOS build is a DMG on the GitHub releases page, and the README says to install BlackHole as well. Running from source needs Python 3 and extra modules, and the tray menu needs PyQt5. The README asks for help maintaining the project, and the latest tagged release is from December 2017.
