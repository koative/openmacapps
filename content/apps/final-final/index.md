FINAL|FINAL is a writing app for academics and long-form projects. It has a heading-based outline with section statuses and word goals, a rich-text editor that switches to raw Markdown without losing your place, inline tasks and comments, named versions with restore, and a focus mode. Citations come from Zotero through `/cite`, a bibliography is generated, and documents export to Markdown, TextBundle, Word or PDF, with Zotero markers kept in Word files. It suits people who manage a manuscript with a bibliography and many sections.

It requires macOS 15 Sequoia or later. The zip is signed with a Developer ID certificate and notarized, and the app checks for and installs its own updates. The README calls it beta software and advises frequent backups. Citations need Zotero running with Better BibTeX, and Word and PDF export use Pandoc, which you install separately. Grammar checking uses LanguageTool, and its premium tier needs an API key. PDF export does not yet support bidirectional text.
