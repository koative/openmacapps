HotKey Hub is a menu bar app for keyboard shortcuts. It shows macOS system shortcuts in one panel, lets you bind any key combination to any app, and gives the first ten Dock apps Control-digit shortcuts without setup. While you record a combination it flags clashes with system shortcuts by name, such as the Screenshot shortcut. It suits people who switch between apps all day and want their shortcuts in one place instead of spread across System Settings.

It needs macOS 13 or later and is built for Apple silicon only. The disk image is not notarized, so the first launch has to be allowed in System Settings. Global shortcuts need Accessibility permission. The README says the app runs entirely on the Mac, with no network use or tracking. Support is by optional donation links in the menu.
