digiKam manages a photo collection on your own disks. It scans the folders you point it at, local, removable or on a network, into a database, and then lets you sort, tag, search and edit what it finds. Albums are the folders themselves, while tags work as virtual albums that can cross them.

- Ratings, color labels and pick flags mark items, and filters narrow the view by any of them, by file type or by name.
- Searches run by keyword, date, a timeline, a map position, faces, or visual similarity to find duplicates.
- Face detection and recognition, auto-tagging and quality grading use optional models that are downloaded on demand. The project says they run only on your computer.
- An image editor handles cropping, curves, white balance, noise reduction and lens correction, keeping versions so the original survives.
- A batch queue applies the same tools to many files at once, with settings saved as workflows.

Photos come in from cameras supported by GPhoto2, USB storage or a scanner, with optional renaming and conversion of RAW files to DNG. RAW decoding uses LibRaw, or you can hand files to darktable or RawTherapee. A light table compares similar shots side by side. The database can be SQLite or a MariaDB server, and exports go to local folders, a remote computer, Piwigo, Flickr, Dropbox and other services.

The macOS download page offers an Apple silicon package for macOS 11.3 or later and an Intel package for macOS 10.15 or later.

Adobe presents Lightroom as photo editing and organizing across desktop, web and mobile. digiKam is a desktop application that works on folders you already keep.
