Coincide puts several coding agents in one window: Claude Code, Codex, Cursor, Grok Build, OpenCode and Antigravity share one model picker, and a thread can continue in a different agent partway through. It drives each agent's own command-line tool, so you need that tool installed and signed in, and Coincide does not proxy or meter tokens. It also has git diffs, pull request views, checkpoints and an integrated terminal. It is for developers who already use these agents and want them in one place.

It requires macOS 26 or later, on Apple silicon and Intel Macs. The README says every release is signed with Developer ID and notarized by Apple. The project describes itself as in early development with rough edges. The README warns that Google's terms bar third-party access to Antigravity and that some accounts have been suspended, so read that notice before signing in to Antigravity. Computer Use is off by default.
