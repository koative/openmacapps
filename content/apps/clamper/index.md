Clamper changes the gaps between menu bar icons. A spacing control sets the distance between icons, and a padding control sets the clickable area around each one, either linked to the spacing or set on its own. A live strip preview shows the result, and one click restores the macOS defaults. It suits people who want to tighten a crowded menu bar or give icons more room.

It needs macOS 15.0 (Sequoia) or later and runs on Apple silicon only, since the release binary is arm64. The app is notarized by Apple, so it opens normally.
