Clamper changes how much space macOS leaves between menu bar icons. One control sets the gap between icons in pixels, and a second sets the padding that forms the clickable area around each icon. Padding can follow the spacing automatically or be set on its own.

While you adjust, a strip of sample icons previews the result. One click restores the macOS defaults if you want the stock layout back.

Clamper needs macOS 15 Sequoia or later. Version 1.0.0, released in March 2026, is an Apple silicon build, signed with a Developer ID and notarized. You can install it from the DMG, through the developer's Homebrew tap, or build it yourself with Xcode 26.

The developer credits Barbee, an App Store app for hiding menu bar items, for the starting pixel values. The README also names TighterMenubar and Sindre Sorhus's Menu Bar Spacing, two other apps that adjust the same spacing.
