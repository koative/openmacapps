Float Translator is a small translation window that stays above other apps, including full-screen ones. It can read the clipboard each time the window opens, translate automatically when you copy text, and hide once you copy the translation. It uses the translation service that ships with macOS, so it suits quick translations of snippets while you work in other apps.

It requires macOS 14 or later and is a universal build that runs on Apple silicon and Intel. The DMG is not notarized, so the first launch has to be allowed in System Settings. The code is GPL-3.0, so modified copies you distribute must also be released under GPL-3.0. The README is short and lists no other requirements.
