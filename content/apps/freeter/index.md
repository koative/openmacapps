Freeter puts the tools for each project on one screen of widgets, so changing project swaps the whole set at once. Press Command-Shift-F from anywhere, or click the tray icon, to bring it forward. You pick a project from a drop-down menu, and a project can hold several workflows arranged as tabs.

Widgets do the work:

- Webpage widgets embed web apps, and each can stay signed in to a different account per project, workflow or widget.
- The file opener sends project files and folders to your editing programs in one click.
- The commander runs terminal commands you would otherwise retype.
- Note, to-do list, timer and web query widgets cover quick text, checklists, work intervals and templated searches.

Things you want in every project, such as a timer, go on the Shelf, which stays available whatever project or workflow is open. A dark theme is one switch away. The developer says the app collects and sends no telemetry or usage data.

Freeter 2 still carries a beta label; the current release is 2.8.0-beta from May 2026, and Freeter 1 is no longer supported. Separate DMGs cover Apple silicon and Intel. Gatekeeper rejects the Apple silicon download as it comes.
