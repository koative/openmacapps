SoundCloud for macOS is an unofficial Mac app that opens soundcloud.com in a native window. It adds media keys and Control Center controls, so play, pause and skip work from the keyboard instead of the browser's ±15-second buttons. It is for people who listen to SoundCloud and want a dedicated window instead of a browser tab. SoundCloud does not publish a Mac app, and the project says it is not affiliated with or endorsed by SoundCloud.

Requires macOS 15.2 or later. The DMG is not notarized, so the first launch is blocked until you choose Open Anyway under System Settings › Privacy & Security. Because the app runs SoundCloud's web player, the media controls can stop working if SoundCloud changes its page. The project continues an MIT-licensed project by Romain Lacombe.
