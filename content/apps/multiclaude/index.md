MultiClaude runs several Claude desktop accounts at once. Each account gets its own profile with its own sign-in, chats and settings. A menu bar panel opens or focuses an account, shows which ones are running, and quits them one at a time. Profiles can also open Claude Code in Terminal under the matching account. It is for people who keep separate personal, work and client Claude accounts on one Mac.

It requires macOS 15 or later, the Claude desktop app in Applications, and either Apple silicon or Intel. The release zip is not notarized, so right-click the app and choose Open the first time. It checks GitHub for updates once a day and installs them unless you turn that off. It has no analytics; the optional Show Chat Limits setting reads usage numbers from claude.ai. It is an independent project, not affiliated with Anthropic.
