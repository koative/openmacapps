Image Viewer is a small macOS viewer modeled on Preview. Open one image and step through the other images in its folder with the arrow keys or Space. It zooms, rotates for display only (the file on disk is not changed), sets a desktop picture, shows image information and uses the standard share menu. It suits people who sort through folders of photos or scans and want a light viewer that never edits the originals.

Requires macOS 14 or later and runs on Apple silicon and Intel. The app is not notarized, so macOS blocks the first launch; allow it under System Settings, Privacy & Security, with Open Anyway, as the README describes. The app has no network code and is not sandboxed. The MIT license covers the source code only: the app icon is all rights reserved and is shown here only to identify the app.
