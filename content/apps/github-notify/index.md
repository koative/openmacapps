GithubNotify sits in the menu bar and changes its icon color when you have unread GitHub notifications, so you can see them without opening a browser. It is a small, single-purpose indicator for developers who follow GitHub activity through notifications.

The last release and the last commit are from October 2017, and the README gives no minimum macOS version. Nothing in the project has been updated since then, so compatibility with current macOS is unknown. Building from source needs Carthage and a GitHub OAuth application with notification access. The project is MIT-licensed, and it publishes no notarization status.
