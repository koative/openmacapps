Tarn is a menu bar app for focus and breathing. Focus runs Pomodoro rounds from 15 to 180 minutes, with breaks that can be turned off, a daily schedule and simple daily stats. Breathe offers a slow breathing picture with four rhythms, for sessions of 1 to 20 minutes. Sounds are optional, and Focus stays silent until you turn them on. A floating circle keeps the timer above other windows, and Calm mode hides other apps for a full-screen session. It suits people who want a quiet timer and short breathing breaks at the desk, without an account.

Requires macOS 14 or newer, on Apple silicon or Intel. The only network use is checking GitHub for updates, which the README says sends no personal information. Guided meditation with recorded voices is optional and can be hidden in Settings. The README describes the release build as signed and notarized.
