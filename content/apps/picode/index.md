PiCode is a native macOS window for coding agents. You choose a project and a harness such as Pi, Claude Code, Codex, OpenCode or Muse Code, and PiCode runs that harness as its own process. Chats, file views, diffs and command output sit beside the conversation. It suits developers who already use these agent CLIs and want a desktop interface.

The README asks for macOS 14 or later and at least one supported harness installed on your login shell's PATH. It does not say whether the build is notarized. Pi packages and extensions can run code with your account's permissions, so review them before installing.
