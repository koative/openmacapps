EMU-Script lets you write electronic music as text. You compose in a script editor with syntax highlighting and error checking, and the app plays the result on a multi-track MIDI sequencer. A sheet view scrolls automatically during playback, and the script can use chord progressions, strums, arpeggios, sections and a notation for drum parts. It is for musicians who prefer writing notes as code over working in a timeline.

It needs macOS 26 or later; the minimum version in the app bundle is 26.0. The 1.1 release is a notarized app zip. You need a synthesizer or a MIDI-compatible virtual instrument, since plugins are not supported, and a separate audio app if you want to record the output. The release notes list experimental iPad support. The project documents the language in a user manual and a reference manual.
