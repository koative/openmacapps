QuotaBar shows how much of your Codex usage remains in the 5-hour and weekly windows, and when each window resets. It refreshes about every minute and signs in through the official Codex ChatGPT flow, so you do not hand over an API key, password or token. It is for people who use Codex heavily and want to check their limits without opening Codex or ChatGPT. The README also describes a compact floating HUD, a right-click status menu and a global shortcut.

Requires macOS 14 or later on an Apple silicon Mac; the README says there is no Intel build. The README says the GitHub download is ad-hoc signed and not notarized, so the first launch needs Open Anyway under System Settings › Privacy & Security. The README says the app has no ads or analytics SDKs, and it describes sponsorship as voluntary.
