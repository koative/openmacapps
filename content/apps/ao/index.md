Ao is an unofficial, open-source desktop app for Microsoft To-Do lists and tasks. It adds black, dark and sepia themes, a compact window mode, keyboard shortcuts for moving between lists and editing todos, and optional global shortcuts that create a todo or search from anywhere. It suits people who keep their tasks in Microsoft To-Do and want a faster window on the desktop.

The README says Ao is not affiliated with Microsoft and that the Homebrew Cask version can lag behind GitHub releases. The releases page offers a Mac zip and a DMG. The latest release is from May 2019, although the repository was last pushed in November 2025.
