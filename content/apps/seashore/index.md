Seashore edits raster images in layers. Open a photo or start a blank canvas, which can have a transparent background, and paint, select and retouch on separate layers before merging them.

- Selection tools cover rectangles, ellipses, the lasso and the polygon lasso, with an aspect ratio setting.
- A clone tool and an effects tool sit next to the painting tools.
- Text layers take several lines and can have an outline.
- Filter plug-ins include hue and saturation, sharpening, posterize and CMYK, and many more come from Core Image.

It opens PNG, JPEG, JPEG 2000, HEIC, WebP, GIF, TIFF, BMP, SVG and PDF files, and it edits GIMP's XCF format.

Mark Pazolli started Seashore on SourceForge, and Robert Engels maintains this version. It is free on the Mac App Store, with an optional in-app purchase to support the project, and needs macOS 10.9 or later. The developer says it collects no personal information.

Engels has moved his main work to Seahorse, a new commercial editor written in Swift for macOS 13 and later, with a separate iPad version. He says Seashore stays free on the App Store and that he will try to keep it running on newer macOS versions and fix critical bugs people report. The last tagged source release on GitHub is 3.36 from June 2024.

Apple's Pixelmator Pro edits images on Mac and iPad, adds AI features built on Apple Intelligence and comes as part of the Apple Creator Studio collection. Seashore has none of that tie-in: it is free, and its source code is public under GPL-2.0.
