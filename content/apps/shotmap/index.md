ShotMap is for finding a clip without playing every file in a folder. It picks a set of frames from a video, lays them out in a grid from 3 × 3 to 8 × 8, and saves the result as a PNG or JPG next to the original. A manual frame editor lets you replace any frame before you export. It suits people who keep family or travel footage, and video editors who want to scan a batch of clips before they start a timeline.

The upstream README says the app needs macOS 13 or later and ships separate Apple silicon and Intel DMGs. It is not notarized yet, so the first launch needs Control-click, then Open, in the Applications folder. Videos stay on the Mac, and the optional update check reads only public GitHub release data.
