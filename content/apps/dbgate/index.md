DbGate keeps connections to several SQL and NoSQL databases open at once, and in each you browse tables, run queries and change data or structure. The free Community edition handles MySQL, MariaDB, PostgreSQL, CockroachDB, SQL Server, Oracle, SQLite, DuckDB, Firebird, ClickHouse, Cassandra, MongoDB and Redis. Redshift, DynamoDB, Firestore, Turso and a few others need Premium.

- Table views have Excel-like and multi-value filters, plus a form view for tables with many columns.
- Data edits come with a preview of the SQL change script, and tables, indexes and keys are editable too.
- The SQL editor formats and completes code, and query results can be filtered, sorted and exported.
- ER diagrams show how a database's tables relate.
- Import and export handle CSV, Excel, JSON, NDJSON, XML and DBF.

MongoDB collections get a JSON view, and Redis gets a key tree and a script runner. The same code also runs as a web app from Docker or npm.

Mac downloads come as Apple silicon, Intel and Universal disk images. The GitHub release lists Community and Premium builds side by side, so pick a file without "premium" in its name.

The paid Premium edition adds the visual query designer, master/detail views, charts, and schema compare and deploy. TablePlus covers many of the same databases and is sold as a per-device license, while DbGate Community is free under GPL-3.0.
