Apple Juice is a battery gauge for macOS. It estimates how much battery time remains and sends a notification when the charge reaches percentages you pick, and a Today widget shows the battery stats at a glance. It suits people who want detailed battery information that feels like part of macOS, without a full system monitor.

The README says the app is not signed with a paid Apple Developer account and describes Gatekeeper workarounds, so you must allow the first launch yourself under System Settings > Privacy & Security. The README does not state a macOS version. The latest release is 2020.12.0, and the last commit is from April 2021.
