AgentPet shows the state of several AI coding agents in the menu bar: Claude Code, Codex, Gemini CLI and Cursor, among others. Each agent is connected by installing a hook from Settings. The menu lists every agent with its project and whether it is working, waiting for input or done. A small desktop pet reacts to that state. The pet gains experience from the tokens your agents use and the sessions they finish, and it can evolve as you code. It suits developers who run several coding agents at once.

AgentPet runs on macOS 13 or later as a universal build. The DMG is Developer ID-signed and notarized, and it updates from the menu bar. The app works offline. Signing in with GitHub is optional and adds a web profile, a leaderboard and cross-device sync of pets. AgentPet bundles no pet artwork: pets are added at runtime and belong to their creators.
