Google Chrome is a web browser built on the open-source Chromium project with Google's own additions, such as account sync, built-in Google services and automatic updates. The Chrome build itself is distributed under Google's terms rather than an open-source licence.

The open-source browsers below do the same job of everyday web browsing with extension support. Brave, ungoogled-chromium and Helium are built on Chromium, so most Chrome extensions work in them, while Firefox, Waterfox, Floorp and Zen use Mozilla's Gecko engine and Firefox add-ons. They differ in default privacy settings, interface layout and update schedules.
