Keyboard Maestro builds macros from a large library of actions, from typing text and clicking to launching apps, moving windows and running scripts. Each macro can start from a hotkey, an app becoming active, a timer or many other triggers.

The open-source apps below cover the same idea of triggered automation in different ways. Keyboard Cowboy is closest in approach, with a visual editor for workflows started by shortcuts or the frontmost app. CrossMacro records and replays clicks and keystrokes from hotkeys, schedules or window focus. Hammerspoon does the job through Lua scripts instead of a graphical editor, trading quick setup for flexibility.
