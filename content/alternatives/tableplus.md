TablePlus is a GUI client for relational and NoSQL databases. It connects to engines such as PostgreSQL, MySQL, SQLite and Redis, shows tables in an editable grid, and includes a SQL editor, SSH tunnelling and multiple connection tabs.

The open-source clients below do the same job of connecting to several database engines and editing data through a grid and query editor. TablePro is a native Mac app, while DBeaver runs on Java and Beekeeper Studio, DbGate and Sqlectron are built on web technologies. They differ in which engines they support and how much administration tooling they include.
