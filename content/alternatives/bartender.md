Bartender keeps a crowded menu bar under control by hiding icons you rarely need and revealing them on demand, from a click, a hotkey or an automatic trigger. It can also move items into a separate bar, search them from the keyboard and switch between layouts.

The open-source apps below do the same core job: they tuck extra menu bar items behind a separator or into a second bar or panel, and some add search, spacing, profiles and triggers. They run locally, need no account and publish their source code. Menu bar changes in macOS 27 have broken some menu bar managers, so check each project's notes on which macOS versions it supports.
