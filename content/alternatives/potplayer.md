PotPlayer is a media player known for playing almost any file, decoding video with hardware acceleration, handling subtitles in detail and supporting 3D output modes, with a long list of settings to tune. It is released for Windows only.

People looking for PotPlayer for Mac usually choose between a few open-source players. IINA wraps the mpv engine in a native Mac interface with picture-in-picture and trackpad gestures, and mpv itself is a minimal, keyboard-driven player with a configuration file for those who want PotPlayer-style control. VLC plays nearly any file or stream with many built-in options, and Mac Classic Player offers a lighter, Media Player Classic-style window with a playlist.
