Microsoft Word is a word processor for writing and formatting documents, from letters to long reports, with styles, comments, tracked changes and shared editing through Microsoft 365. The open-source apps below do the same core job on the Mac: they create and edit formatted documents, and they open and save Word's .docx files alongside their own formats.

LibreOffice Writer, part of the LibreOffice suite, uses OpenDocument Text as its native format and covers styles, templates, tracked changes and PDF export. ONLYOFFICE Desktop Editors works with the Office Open XML formats natively and uses a tabbed, ribbon-style toolbar that feels closer to Word. Complex layouts can shift when a file moves between apps, so check important documents before sending them.
