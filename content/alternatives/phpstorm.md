PhpStorm is JetBrains' IDE for PHP. It indexes a whole project to offer completion, navigation and refactoring across files, and bundles support for PHP frameworks, Xdebug, PHPUnit, databases and the JavaScript and TypeScript side of a web project.

The open-source apps below can take over day-to-day PHP development. Apache NetBeans is the closest match: a full IDE with built-in PHP support, project management and a debugger. VSCodium is a lighter code editor that ships basic PHP language features and relies on extensions from the Open VSX registry for deeper code intelligence and debugging, so the setup takes more assembly than an IDE that works out of the box.
