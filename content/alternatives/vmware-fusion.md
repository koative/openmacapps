VMware Fusion is a desktop hypervisor that runs other operating systems as virtual machines on macOS. It manages virtual disks, networking and snapshots, and shares the virtual machine format of VMware's other virtualisation products.

The open-source apps below do the same job of creating and running virtual machines on a Mac. UTM combines Apple's virtualisation framework with QEMU emulation for guests built for other architectures, and VirtualBox is a cross-platform virtualiser that can import and export common appliance formats. Guest operating systems and their licences are obtained separately.
