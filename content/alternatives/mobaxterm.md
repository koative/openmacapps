MobaXterm bundles the tools of remote administration into one program: a tabbed terminal for SSH and other protocols, a graphical SFTP browser beside each session, a built-in X11 server for remote graphical programs, and a set of network utilities. Mobatek builds it as a single Windows application.

For MobaXterm for Mac, electerm comes closest, with saved sessions for SSH, Telnet and serial ports, an SFTP and FTP file panel, and RDP and VNC connections in the same tabbed window. Netcatty pairs tabbed SSH, Telnet, Mosh and serial sessions with a dual-pane SFTP browser. Tabby covers SSH and serial sessions in tabs with SFTP transfers, and it is more of a customisable terminal. None of them includes an X11 server; on the Mac that part comes from the separate XQuartz project.
