AutoHotkey is a scripting language for desktop automation: scripts define hotkeys for the keyboard and mouse, remap keys, expand abbreviations, and drive windows and programs. It is open source and runs only on Windows.

There is no AutoHotkey for Mac, and no single Mac app reads its scripts, so its jobs are split across tools. Hammerspoon is the closest in spirit, a scripting bridge where Lua code binds hotkeys, moves windows and reacts to system events. Keyboard Cowboy builds shortcut-triggered workflows in a visual editor without code, and Karabiner-Elements handles the remapping side, from swapping single keys to complex rules.
