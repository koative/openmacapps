Sublime Text is a cross-platform editor for code and prose. It is known for multiple cursors, a command palette, Goto Anything navigation and a large catalogue of community packages.

The open-source editors below cover the same everyday job of editing code across many languages. Zed and Lapce are written in Rust and include language server support, Lite XL is a small editor extended with Lua plugins, Pulsar continues the extensible Atom editor, and TextMate is a native Mac editor built around language bundles. They differ in plugin ecosystems and how much IDE tooling they ship by default.
