Tower is a desktop Git client for Mac and Windows. It puts staging, committing, branching, merging, rebasing and history browsing into a graphical interface, and connects to hosting services such as GitHub and GitLab.

The open-source Git clients below do the same core job of working with repositories without typing Git commands. GitHub Desktop focuses on a simple workflow tied to GitHub, GitUp is built around an interactive history graph, and Gittyup, GitX, Xit and Changes offer history views, hunk staging and branch management. They vary in how many advanced operations, such as interactive rebase or submodules, they expose.
