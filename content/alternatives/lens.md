Lens is a desktop app for working with Kubernetes. It reads the clusters in your kubeconfig and lets you browse workloads, read logs, open shells in containers and edit resources from one window instead of the command line. The current Lens Desktop is not open source and is offered with paid plans and a Lens ID account.

The apps below are free desktop clients for the same job. Freelens grew out of the community fork of Lens's earlier open-source code, so it is the closest to the original. Headlamp is a dashboard from the Kubernetes SIG UI project that runs as a desktop app and can be extended with plugins. JET Pilot is a lighter client that also manages Helm charts.
