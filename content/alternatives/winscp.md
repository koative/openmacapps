WinSCP moves files between a local computer and remote servers over SFTP, FTP, FTPS, SCP, WebDAV and Amazon S3, with a two-panel or Explorer-style interface, a built-in text editor and scripting for automated transfers. It is open source and made for Windows only.

Cyberduck is the usual answer for WinSCP for Mac: it browses SFTP, FTP, WebDAV and S3 servers as well as cloud storage services, and opens remote files in your own editor. FileZilla Client sticks to FTP, FTPS and SFTP with local and remote folders side by side and a transfer queue. electerm and Netcatty approach it from the terminal side, pairing SSH sessions with a file panel (SFTP in both, FTP too in electerm), so they suit people who switch between a shell and file transfers on the same server.
