iStat Menus puts live readings for the processor, graphics, memory, disks, network, sensors and battery into the menu bar. Each item opens a detailed menu with history graphs and top processes, and the app can send alerts based on rules and adjust fan speeds.

The open-source apps below share the same core job: compact system figures in the menu bar, with more detail one click away. They differ in scope. Some read temperatures, fans and power draw where the hardware allows it, while others deliberately stick to a few load and usage figures. Several target Apple silicon only, so check each project's requirements.
