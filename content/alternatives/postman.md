Postman is a desktop and web workspace for working with APIs: you compose requests, inspect responses, group requests into shared collections, switch between environments and run test scripts against the results. Much of its collaboration happens through a cloud account.

The open-source apps below cover the same core job of building, sending and organising API requests on a Mac. Bruno and Yaak keep collections as files you can commit next to your code, Insomnia focuses on designing and debugging requests, and Hoppscotch packages its web-based API workspace as a desktop app. Check each one for the protocols you rely on, such as GraphQL, gRPC or WebSockets.
