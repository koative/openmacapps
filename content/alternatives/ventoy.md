Ventoy prepares a USB drive once and then boots ISO, WIM, IMG, VHD(x) and EFI files copied straight onto it, showing a menu when several images sit on the same stick. It is open source, and its installer runs on Windows and Linux; the project offers no macOS version.

Anyone searching for Ventoy for Mac mainly needs a bootable USB drive made from an image file, and balenaEtcher and macUSB do that on the Mac. balenaEtcher writes one image to a USB drive or SD card and checks the write, while macUSB guides you through installer drives for macOS, Linux and Windows. Both write a single system per drive, so the multi-image boot menu that sets Ventoy apart has no direct equivalent among them.
