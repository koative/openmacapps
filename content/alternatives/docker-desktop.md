Docker Desktop sets up a Linux virtual machine on the Mac, runs the Docker engine inside it, and adds a window for managing containers, images, volumes and an optional local Kubernetes cluster.

The open-source apps below also provide a local container runtime plus a desktop interface to manage it. Podman Desktop is built around the daemonless Podman engine and can also work with other engines, while Rancher Desktop offers a choice of container runtime and bundles a local Kubernetes cluster. Both can run many existing Docker images and Compose workflows, but check compatibility for your own setup.
