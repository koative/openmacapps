Task Manager is the Windows utility that lists running apps and processes, ends programs that stop responding, graphs CPU, memory, disk and network performance, and controls which apps start with Windows. It is part of Windows and has no Mac edition.

macOS includes its own Task Manager for Mac: Activity Monitor, in the Utilities folder, shows processes and their resource use and can force quit them. The open-source apps below are extras for people who want a different view. NeoHtop gives a searchable, sortable process list with pinned processes, TaskExplorer shows each process's code signature, loaded libraries, open files and network connections, and Stats keeps CPU, memory and network usage visible in the menu bar.
