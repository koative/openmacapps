Notepad++ is a source code and plain-text editor built on the Scintilla editing component. It opens files in tabs, highlights the syntax of many programming languages, records macros, searches and replaces across whole folders, and grows through a plugin system. It is itself open source, but it is written against the Win32 API and runs only on Windows.

Two projects aim straight at people looking for Notepad++ for Mac. Nextpad++ is a macOS port that keeps the familiar menus, macros, plugins and find-in-files, while Notepad Next rebuilds the same interface as a cross-platform app with its own Mac disk images. CotEditor and TextMate are native Mac editors rather than copies: CotEditor stays close to the quick plain-text and script editing many people use Notepad++ for, and TextMate adds language bundles, snippets and project navigation.
