Fork is a desktop Git client for Mac and Windows. It shows the commit graph next to working copy changes, stages individual lines, and covers branching, merging, rebasing, stashes and submodules from a graphical interface, with extras such as interactive rebase, blame, image diffs and a merge conflict resolver.

The open-source Git clients below do the same core job of working with repositories without typing Git commands. GitHub Desktop keeps the workflow simple and close to GitHub, GitUp centres everything on an editable history graph, and Gittyup, GitX, Xit and Changes provide history views, hunk staging and branch management in native or cross-platform windows. RelaGit is newer and still in early beta. They differ mainly in how many advanced operations, such as interactive rebase, they expose.
