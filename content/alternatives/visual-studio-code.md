Visual Studio Code is a code editor with an extension marketplace, language server support, an integrated terminal, a debugger and built-in Git tools. Its source code is published as the open-source Code - OSS project, but the official build from Microsoft is distributed under a proprietary licence and includes telemetry and Microsoft services.

The apps below replace the official build for day-to-day coding. VSCodium is built from the same source code without Microsoft's branding and telemetry, and uses the Open VSX extension registry. Zed, Lapce and Pulsar are separate editors with their own extension systems, so existing VS Code extensions do not carry over to them.
