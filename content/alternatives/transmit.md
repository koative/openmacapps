Transmit is Panic's file transfer app for the Mac. It uploads, downloads and manages files on FTP, SFTP and WebDAV servers, Amazon S3 buckets and cloud storage services, using a dual-pane view, saved server bookmarks and folder sync between local and remote locations.

The open-source apps below do the same core job of moving files between a Mac and remote servers. Cyberduck is the closest match, covering SFTP, FTP and WebDAV along with S3 and other cloud storage, and it opens remote files in the editor you already use. FileZilla Client concentrates on FTP, FTPS and SFTP with a two-pane view and a transfer queue; cloud storage is limited to its paid Pro edition.
