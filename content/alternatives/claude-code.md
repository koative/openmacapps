Claude Code is Anthropic's agentic coding tool. Given a task, it explores a repository, plans changes, edits files and runs commands, and can be driven from a terminal, an IDE extension, a desktop app or the web. Its code is not open source, and it works with Anthropic's models through a Claude subscription or API access.

The apps below are coding agents in their own right, not interfaces that launch Claude Code. OpenCode is the closest match: a terminal-first agent that plans and edits code and connects to many model providers. Warp is a terminal with its own built-in agent alongside its command line, and OpenBitFun is a desktop agent workspace whose coding agent runs on a Rust runtime and can split larger tasks across several agents. All of them need a model provider or account to do any work.
