tags:
  - git-client
---

A Git client gives version control a visual interface: a history graph, side-by-side diffs, staging of individual lines or hunks, and branch management without typing commands.

Check how each client handles the operations you use most, such as interactive rebase, stashes, submodules or worktrees, whether it works with any remote or is built around one hosting service, and whether it uses the Git already installed on your Mac.
