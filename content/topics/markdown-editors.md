---
title: "Markdown editors"
description: "Open-source Markdown editors for Mac with live preview, syntax highlighting and export, working on plain .md files you keep yourself."
tags:
  - markdown-editor
---

A Markdown editor lets you write formatted documents in plain text, using simple marks for headings, lists, links and emphasis. Some show a live preview beside the source, others render formatting inline as you type.

Because Markdown files are plain text, your writing stays readable in any other app. When comparing editors, check whether they open ordinary .md files where they already live, which Markdown flavours and extensions they support (tables, footnotes, math, diagrams) and which export formats they offer.
