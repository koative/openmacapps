---
title: Keyboard customization tools
description: Open-source Mac utilities that remap keys, change how function, Caps Lock and Globe keys behave, and switch input sources automatically.
tags:
  - keyboard-customization
---

macOS offers a few keyboard settings, such as modifier key swaps and function key behaviour, but not much beyond that. The utilities here change what keys do: remapping individual keys or combinations, adjusting the function row per app, removing the Caps Lock delay, or switching input sources automatically.

Most of them need Accessibility or Input Monitoring permission, and some install a system driver, so check how each one is installed and removed. Look for per-app or per-device rules if you use more than one keyboard, and for a way to export your configuration.
