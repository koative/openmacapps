---
title: Tiling window managers
description: Open-source tiling window managers for Mac that lay windows out automatically in non-overlapping tiles, controlled from the keyboard.
tags:
  - tiling
---

A tiling window manager places every window in a non-overlapping layout, so opening or closing an app reflows the others instead of leaving them stacked on top of each other. Most are driven from the keyboard and have their own workspaces alongside or instead of macOS Spaces.

They differ in how layouts are built, such as binary space partitioning, a fixed set of layouts or scrolling columns, and in how they are configured, often through a text file. Some features need extra system permissions or changed security settings, so read each project's setup notes before installing.
