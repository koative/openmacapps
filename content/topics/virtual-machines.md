---
title: "Virtual machine apps"
description: "Open-source virtual machine apps for Mac to run Linux, Windows or macOS guests alongside your main system."
tags:
  - virtual-machines
---

Virtualisation software runs another operating system inside a window on your Mac. It is useful for testing software, using Linux tools or trying a beta version of macOS without touching your main system.

On Apple silicon, guests usually need to be built for ARM, and running other architectures requires slower emulation. Check which guest systems each app supports, whether it uses Apple's Virtualization framework, and how it handles shared folders, networking and snapshots.
