---

Preview on the Mac can read and mark up PDFs, but many everyday tasks need more: merging and splitting files, reordering pages, compressing, converting, running OCR on scans or writing on a page with a pen.

The tools below handle those jobs locally, so documents do not have to be uploaded to a web service. Check which operations each app covers, whether it processes files in batches, and whether OCR or scanning is included if you work with paper documents.
