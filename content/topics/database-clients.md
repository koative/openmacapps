title: "Database clients"

tags:

---

A database client connects to a database server or file and lets you browse tables, edit rows and run queries without the command line. The apps below cover SQL engines such as PostgreSQL, MySQL and SQLite, and key-value stores such as Redis.

Check which engines each client supports, whether it can connect through SSH tunnels, how it stores saved connections and passwords, and whether its query editor offers completion and result export.
