---
title: "API clients"
description: "Open-source API clients for Mac to build and send HTTP requests, organise collections and inspect responses and traffic."
tags:
  - api-client
---

An API client lets you compose HTTP requests, send them to a server and inspect the response, so you can test and debug web APIs without writing code. Most also save requests in collections and support environments for switching between servers.

Check where collections are stored (local files you can commit alongside your code, or a cloud account), which protocols are supported beyond REST, such as GraphQL or gRPC, and whether the app can intercept traffic from other programs.
