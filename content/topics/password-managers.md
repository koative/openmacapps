---
title: Password managers
description: Open-source password managers for Mac that keep passwords and other secrets in an encrypted vault, stored locally or synced through a server.
tags:
  - password-manager
---

A password manager stores your logins, and often passkeys, cards and notes, in an encrypted vault so you can use a unique password for every account and unlock them all with one master password.

The main choice is where the vault lives: in a local file you sync yourself, such as a KeePass database, or on a server run by the project or by you. Because the code is open, its encryption can be reviewed. Check which browsers and platforms each one supports and how it handles backups and import from your current tool.
