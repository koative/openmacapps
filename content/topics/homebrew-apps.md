---
title: Homebrew apps
description: Open-source Mac apps that put a graphical interface on Homebrew to search, install, update and remove formulae and casks without the Terminal.
tags:
  - package-manager
---

Homebrew is a package manager for macOS that installs command-line tools as formulae and Mac apps as casks, normally through the Terminal. The apps here provide a window or menu bar interface on top of it, so you can browse packages, see what is outdated and install or remove software with a click.

They differ in scope. Some handle casks only and present them like an app store, others cover formulae, taps and services too, and one sits in the menu bar to check for updates. Consider whether you also manage command-line tools, and whether the app expects an existing Homebrew installation or can set one up.
