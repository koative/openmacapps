A code editor is a text editor built for source code: syntax highlighting, project-wide search, multiple cursors and, in most cases, language servers for completion and diagnostics. An IDE goes further with build, run and debugging tools for particular languages.

The editors below range from small, fast apps for quick edits to full development environments. Look at the languages and extensions you rely on, whether the interface is native or cross-platform, how settings are stored, and whether features like collaboration or a built-in terminal matter to you.
