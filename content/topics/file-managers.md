---
title: File managers
description: Open-source file managers that work as a Finder replacement on Mac, with dual panes, tabs and keyboard commands for moving and organising files.
tags:
  - file-manager
---

The Finder covers everyday browsing, but heavy file work can be slow with a mouse, which is when a Finder replacement starts to pay off. The file managers here add two side-by-side panes, tabs, keyboard commands for copying and moving, batch renaming and browsing inside archives or remote locations, while the Finder stays available for everything else.

Several follow the orthodox two-panel style of Norton Commander, Total Commander or FAR Manager, while others use Vim-style keys or a command palette. Check how each one integrates with Finder features you rely on, such as tags, Quick Look and iCloud Drive.
