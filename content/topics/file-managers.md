---
title: File managers
description: Open-source file managers for Mac with dual panes, tabs and keyboard-driven commands, as alternatives to the Finder for moving and organising files.
tags:
  - file-manager
---

The Finder covers everyday browsing, but heavy file work can be slow with a mouse. Alternative file managers add two side-by-side panes, tabs, keyboard commands for copying and moving, batch renaming and browsing inside archives or remote locations.

Several follow the orthodox two-panel style of Norton Commander, Total Commander or FAR Manager, while others use Vim-style keys or a command palette. Check how each one integrates with Finder features you rely on, such as tags, Quick Look and iCloud Drive.
